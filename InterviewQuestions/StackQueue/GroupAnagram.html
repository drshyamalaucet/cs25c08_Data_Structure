Group Anagrams

Interactive Data Structure & Algorithm Visualizer

1. Problem Statement

Given an array of strings, group all the strings that are anagrams of each other.

Two strings are anagrams if they contain the same characters with the same frequencies, but possibly in a different order.

Example:

Input:
["eat", "tea", "tan", "ate", "nat", "bat"]

Output:
[
    ["eat", "tea", "ate"],
    ["tan", "nat"],
    ["bat"]
]

4. Key Idea

We use a hash map to store groups of anagrams.

For every word, we sort its characters. The sorted version becomes the key. 

"eat" → "aet"
"tea" → "aet"
"ate" → "aet"

"tan" → "ant"
"nat" → "ant"

"bat" → "abt"

Therefore, words with the same sorted key belong to the same anagram group.

5. Pseudocode

function groupAnagrams(strs):

    create empty hash map groups

    for each word in strs:

        key = sort(word)

        add word to groups[key]

    return all values of groups

6. Python Implementation

from collections import defaultdict

def group_anagrams(strs):

    groups = defaultdict(list)

    for word in strs:

        # Sort characters to create the key
        key = ''.join(sorted(word))

        # Add word to the corresponding group
        groups[key].append(word)

    return list(groups.values())


# Example
words = [
    "eat",
    "tea",
    "tan",
    "ate",
    "nat",
    "bat"
]

result = group_anagrams(words)

print(result)

7. Python Code Explanation

Step 1: Create a dictionary using defaultdict(list).

Step 2: Process each word in the input array.

Step 3: Sort the characters of the word.

For example: 

eat → aet
tea → aet
ate → aet

Since all three words produce the same key "aet", they are placed in the same group.

Similarly: 

tan → ant
nat → ant

Therefore, tan and nat are placed together.

8. Complexity Analysis

Time Complexity O(N × K log K)
Each of N strings is sorted.
Space Complexity O(N × K)
Hash map stores all strings and keys.
N Number of strings in the array.
K Maximum length of a string.

9. Alternative Approach — Character Frequency

Instead of sorting every word, we can count the frequency of each character. 

"eat"

a → 1
b → 0
c → 0
...
e → 1
...
t → 1

The 26-character frequency array can be used as the hash-map key. 

from collections import defaultdict

def group_anagrams(strs):

    groups = defaultdict(list)

    for word in strs:

        count = [0] * 26

        for ch in word:
            count[ord(ch) - ord('a')] += 1

        key = tuple(count)

        groups[key].append(word)

    return list(groups.values())

For lowercase English letters, this approach can achieve approximately O(N × K) time.
