Contains Duplicate

Interactive Array & Hash Set Visualizer

1. Problem Statement

Given an array of integers, return true if any value appears at least twice.

Return false if every element in the array is distinct.

Example 1:

Input:
[1, 2, 3, 1]

Output:
true

Explanation:
The value 1 appears twice.

Example 2:

Input:
[1, 2, 3, 4]

Output:
false

Explanation:
Every value appears exactly once.

4. Algorithm

Step 1 Create an empty hash set.
Step 2 Traverse the array from left to right.
Step 3 Check whether the current value is already in the set.
Step 4 If it exists, a duplicate has been found.
Step 5 Otherwise, add the value to the set.
Step 6 If traversal finishes without finding a duplicate, return false.

6. Pseudocode

function containsDuplicate(nums):

    create empty hash set

    for each num in nums:

        if num is already in set:
            return true

        add num to set

    return false

7. Python Implementation

def contains_duplicate(nums):

    seen = set()

    for num in nums:

        if num in seen:
            return True

        seen.add(num)

    return False


# Example
nums = [1, 2, 3, 1]

result = contains_duplicate(nums)

print(result)

Output:

True

8. Short Python Solution

def contains_duplicate(nums):
    return len(nums) != len(set(nums))

A Python set stores only unique values.

Therefore, if: 

len(nums) != len(set(nums))

then at least one duplicate exists.

9. Python Code Explanation

The main solution uses a set called seen.

For every element, we first ask: 

if num in seen:

If the answer is True, we have already seen the number before, so it is a duplicate.

Otherwise, we insert the number: 

seen.add(num)

For the input: 

[1, 2, 3, 1]

the fourth element is 1, which already exists in the set. Therefore the algorithm immediately returns True.

10. Complexity Analysis

Time Complexity O(n)

Each element is checked in the hash set once on average.
Space Complexity O(n)

In the worst case, all elements are distinct and stored in the set.

11. Alternative Approach — Sorting

Another solution is to sort the array and compare adjacent elements. 

def contains_duplicate(nums):

    nums.sort()

    for i in range(1, len(nums)):

        if nums[i] == nums[i - 1]:
            return True

    return False

However, sorting requires O(n log n) time.

The hash-set solution provides approximately O(n) average time.

12. Important Observation

The key operation is: 

if num in seen:

A hash set allows average O(1) membership checking.

This allows us to detect duplicates efficiently without comparing every pair of elements.

Once a duplicate is found, we can immediately return True.
