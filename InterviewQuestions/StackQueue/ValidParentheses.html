Bracket Matching

( → )
{ → }
[ → ]

When an opening bracket is encountered, it is pushed onto the stack. When a closing bracket is encountered, the top element of the stack must be its corresponding opening bracket.

Pseudocode

``` 
function isValid(s):

    stack = empty stack

    for each character ch in s:

        if ch is '(' or '{' or '[':
            push ch onto stack

        else:
            if stack is empty:
                return false

            top = pop stack

            if ch == ')' and top != '(':
                return false

            if ch == '}' and top != '{':
                return false

            if ch == ']' and top != '[':
                return false

    return stack is empty
```

Python Implementation

``` 
def is_valid(s):
    stack = []

    pairs = {
        ')': '(',
        '}': '{',
        ']': '['
    }

    for ch in s:

        # Opening bracket
        if ch in "({[":
            stack.append(ch)

        # Closing bracket
        else:
            if not stack:
                return False

            top = stack.pop()

            if pairs[ch] != top:
                return False

    return len(stack) == 0


# Example
s = "({[]})"

print(is_valid(s))
# Output: True
```

Explanation

  • Use a stack to store opening brackets.
  • Opening brackets (, {, [ are pushed onto the stack.
  • For a closing bracket, compare it with the most recent opening bracket.
  • If they match, remove the opening bracket using pop().
  • If they do not match, the string is invalid.
  • At the end, the stack must be empty for the string to be valid.

Examples

  • () → Valid
  • ()[]{} → Valid
  • ({[]}) → Valid
  • (] → Invalid
  • ([)] → Invalid
  • (( → Invalid

Complexity Analysis

  • Time Complexity: O(n)
  • Space Complexity: O(n)

Each character is processed once, and every opening bracket is pushed and popped at most once.
