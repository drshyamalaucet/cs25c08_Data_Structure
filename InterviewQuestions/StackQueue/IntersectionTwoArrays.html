Intersection of Two Arrays

Interactive Set-Based Algorithm Visualizer

1. Problem Statement

Given two integer arrays, return an array containing their intersection.

Each element in the result must be unique.

Example: nums1 = [1, 2, 2, 1], nums2 = [2, 2]

Output: [2]

5. Algorithm

  1. Create a set containing all unique elements of Array 1.
  2. Create an empty result set.
  3. Traverse Array 2.
  4. For each element, check whether it exists in the Array 1 set.
  5. If it exists, add it to the result set.
  6. Because a set contains only unique values, duplicates are automatically removed.
  7. Convert the result set into an array.

6. Pseudocode

FUNCTION intersection(nums1, nums2)

    set1 ← empty set
    result ← empty set

    FOR each num IN nums1
        add num to set1
    END FOR

    FOR each num IN nums2

        IF num exists in set1 THEN
            add num to result
        END IF

    END FOR

    RETURN result as an array

END FUNCTION

7. Python Implementation

def intersection(nums1, nums2):
    set1 = set(nums1)
    result = set()

    for num in nums2:
        if num in set1:
            result.add(num)

    return list(result)


# Example
nums1 = [1, 2, 2, 1]
nums2 = [2, 2]

print(intersection(nums1, nums2))

Output: [2]

8. Short Python Solution

def intersection(nums1, nums2):
    return list(set(nums1) & set(nums2))

The & operator performs set intersection.

9. Explanation

  • A set stores only unique elements.
  • Therefore, duplicates in the input arrays do not create duplicate values in the answer.
  • We first convert Array 1 into a set so membership checking is efficient.
  • We then examine every element of Array 2.
  • If the element exists in the first set, it belongs to the intersection.
  • The result is also stored in a set, ensuring that every result element is unique.

10. Complexity Analysis

Time Complexity

O(n + m) average time

where n is the length of Array 1 and m is the length of Array 2.

Space Complexity

O(n) auxiliary space

for storing the unique elements of Array 1.

11. Important Observation

This problem is different from the Intersection of Two Arrays II.

Here, duplicates are ignored.

For example:

[1, 2, 2, 3] ∩ [2, 2, 2, 3]

Result: [2, 3]

The value 2 appears only once in the result because the problem requires every result element to be unique.
