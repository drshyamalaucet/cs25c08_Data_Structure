Largest Rectangle in Histogram

Interactive Monotonic Stack Visualizer

1. Problem Statement

Given an array of non-negative integers representing the heights of histogram bars, find the area of the largest rectangle that can be formed within the histogram.

Example:

Input: [2, 1, 5, 6, 2, 3]

The largest rectangle has:
Height = 5
Width = 2
Area = 5 × 2 = 10

Answer = 10

3. Algorithm

  1. Traverse the histogram from left to right.
  2. Maintain a stack containing indices of bars whose left boundary has not yet been determined.
  3. The heights corresponding to stack indices are maintained in increasing order.
  4. When the current bar is shorter than the stack-top bar, the rectangle represented by the stack-top bar can no longer extend to the right.
  5. Pop that index from the stack.
  6. Calculate the rectangle width using the current index and the new stack top.
  7. Calculate:

    Area = Height × Width
  8. Update the maximum area.
  9. Push the current index onto the stack.
  10. After processing all bars, process the remaining stack using a virtual bar of height 0.

4. Pseudocode

FUNCTION largestRectangleArea(heights):

    stack = empty stack
    maxArea = 0

    FOR i FROM 0 TO n:

        currentHeight =
            heights[i] if i < n else 0

        WHILE stack is not empty
              AND currentHeight < heights[stack.top]:

            height = heights[stack.pop()]

            IF stack is empty:
                width = i
            ELSE:
                width = i - stack.top - 1

            area = height * width

            maxArea = max(maxArea, area)

        PUSH i onto stack

    RETURN maxArea

5. Python Implementation

def largest_rectangle_area(heights):

    stack = []
    max_area = 0

    # Add a virtual bar of height 0
    heights.append(0)

    for i in range(len(heights)):

        while stack and heights[i] < heights[stack[-1]]:

            height = heights[stack.pop()]

            if not stack:
                width = i
            else:
                width = i - stack[-1] - 1

            area = height * width

            max_area = max(max_area, area)

        stack.append(i)

    heights.pop()

    return max_area


# Example
heights = [2, 1, 5, 6, 2, 3]

answer = largest_rectangle_area(heights)

print("Histogram:", heights)
print("Largest Rectangle Area:", answer)

7. Width Calculation

When a bar of height h is popped, we know that the current index is the first position to the right where a shorter bar occurs.

The new stack top gives the first smaller bar on the left. 

If stack is empty:

    width = current_index

Otherwise:

    width = current_index - stack_top - 1

Therefore: 

Area = height × width

8. Complexity Analysis

Time Complexity

O(n)

Every histogram bar is pushed onto the stack once and popped at most once.

Space Complexity

O(n)

The monotonic stack can contain up to n indices.

9. Why Use a Monotonic Stack?

A brute-force solution would consider every possible rectangle. That can require O(n²) or worse depending on the implementation.

The monotonic stack efficiently identifies the nearest smaller bar on both sides of each histogram bar.

For the example: 

Heights:

2  1  5  6  2  3

             ┌───┐
          ┌──┤ 6 │
          │  └───┘
       ┌──┤ 5
       │  └───────┐
       │           │
───────┴───────────┴────
  0    1   2  3   4  5

Largest rectangle:

Height = 5
Width  = 2

Area = 5 × 2 = 10
