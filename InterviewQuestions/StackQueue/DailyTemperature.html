Daily Temperatures

Interactive Monotonic Stack Visualizer

1. Problem Statement

Given an array of daily temperatures, return an array where each index contains the number of days you have to wait until a warmer temperature.

If there is no future day with a warmer temperature, return 0.

Example:
Input: [73, 74, 75, 71, 69, 72, 76, 73]

Output: [1, 1, 4, 2, 1, 1, 0, 0]

3. Algorithm

  1. Traverse the temperature array from left to right.
  2. Maintain a stack containing indices of temperatures for which we have not yet found a warmer day.
  3. For the current temperature, compare it with the temperature at the index on top of the stack.
  4. If the current temperature is warmer, pop the previous index.
  5. The difference between the current index and the popped index is the number of days waited.
  6. Continue popping while the current temperature is warmer.
  7. Push the current index onto the stack.

The stack maintains temperatures in decreasing order from bottom to top.

4. Pseudocode

FUNCTION dailyTemperatures(temperatures):

    n = length(temperatures)

    result = array of n zeros

    stack = empty stack

    FOR i = 0 TO n - 1:

        WHILE stack is not empty
              AND temperatures[i] >
                  temperatures[stack.top]:

            previous = stack.pop()

            result[previous] = i - previous

        PUSH i into stack

    RETURN result

5. Python Implementation

def daily_temperatures(temperatures):

    n = len(temperatures)

    result = [0] * n

    stack = []

    for i in range(n):

        # Find warmer temperature for previous days
        while stack and temperatures[i] > temperatures[stack[-1]]:

            previous = stack.pop()

            result[previous] = i - previous

        # Current day waits for a warmer future day
        stack.append(i)

    return result


# Example
temperatures = [73, 74, 75, 71, 69, 72, 76, 73]

answer = daily_temperatures(temperatures)

print("Temperatures:", temperatures)
print("Answer:", answer)

7. Complexity Analysis

Time Complexity

O(n)

Every index is pushed onto the stack once and removed at most once.

Space Complexity

O(n)

The stack and result array may contain up to n elements.

8. Why the Monotonic Stack Works

Suppose we have: 

[73, 74, 75, 71, 69, 72, 76, 73]

When we reach 74, it is warmer than 73. Therefore, the answer for 73 is immediately known: 

Day difference = 1 - 0 = 1

Similarly, when we reach 72, it is warmer than 69 and 71. Therefore: 

For 69:
5 - 4 = 1 day

For 71:
5 - 3 = 2 days

The stack allows us to keep only the temperatures that are still waiting for a warmer future temperature.
