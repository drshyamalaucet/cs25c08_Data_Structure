1. Problem Statement

Given an array of integers, find the first greater element to the right of each element. If no greater element exists, return -1.

Example:
Input: [4, 5, 2, 10, 8]
Output: [5, 10, 10, -1, -1]

3. Algorithm Idea

We use a monotonic decreasing stack. We scan the array from right to left.

  1. Take the current element.
  2. Remove all elements from the stack that are smaller than or equal to it.
  3. If the stack is empty, the answer is -1.
  4. Otherwise, the top of the stack is the next greater element.
  5. Push the current element onto the stack.

The stack allows us to avoid repeatedly scanning all elements to the right.

4. Pseudocode

FUNCTION nextGreaterElement(array):

    n = length(array)

    result = array of size n filled with -1

    stack = empty stack

    FOR i = n - 1 DOWNTO 0:

        WHILE stack is not empty
              AND stack.top <= array[i]:

            pop stack

        IF stack is not empty:
            result[i] = stack.top

        push array[i] into stack

    RETURN result

5. Python Implementation

def next_greater_element(arr):
    n = len(arr)

    result = [-1] * n

    stack = []

    # Traverse from right to left
    for i in range(n - 1, -1, -1):

        # Remove elements that cannot be the answer
        while stack and stack[-1] <= arr[i]:
            stack.pop()

        # Top of stack is the next greater element
        if stack:
            result[i] = stack[-1]

        # Push current element
        stack.append(arr[i])

    return result

7. Why Use a Stack?

A simple approach would compare every element with all elements to its right. This can take O(n²) time.

The stack-based approach ensures that each element is pushed onto the stack once and popped at most once.

Time Complexity

O(n)

Each element is pushed and popped at most once.

Space Complexity

O(n)

The stack and result array can contain up to n elements.

8. Important Concept: Monotonic Stack

A monotonic stack is a stack maintained in increasing or decreasing order.

For the Next Greater Element problem, we maintain a stack such that useful candidates for the next greater element remain available.

When processing an element such as 10, smaller values such as 8 can be removed because they cannot be the next greater element for 10. 

Example:

Array: 4  5  2  10  8

Process from right to left:

8
↓
10 removes 8
↓
2 keeps 10
↓
5 removes 2 and keeps 10
↓
4 keeps 5

Result:

5  10  10  -1  -1
