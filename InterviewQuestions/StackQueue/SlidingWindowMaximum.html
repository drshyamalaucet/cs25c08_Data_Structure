Sliding Window Maximum

Interactive Deque-Based Visualizer

1. Problem Statement

Given an array and a sliding window size k, find the maximum value inside the window at each position as the window slides from left to right.

Example:

Array: [1, 3, -1, -3, 5, 3, 6, 7]
k = 3

Output: [3, 3, 5, 5, 6, 7]

3. Algorithm

  1. Maintain a deque containing indices of useful elements.
  2. For every new element, remove indices from the back while their values are smaller than the current value.
  3. Remove the front index if it is outside the current window.
  4. Add the current index to the back of the deque.
  5. When the first complete window is formed, the front of the deque contains the maximum element.
  6. Move the window one position to the right and repeat.

The deque is maintained in decreasing order of values.

4. Pseudocode

FUNCTION maxSlidingWindow(nums, k):

    deque = empty deque
    result = empty array

    FOR i = 0 TO n - 1:

        # Remove indices outside the window
        WHILE deque is not empty
              AND deque.front <= i - k:

            remove front

        # Remove smaller values
        WHILE deque is not empty
              AND nums[deque.back] <= nums[i]:

            remove back

        # Add current index
        add i to back

        # Window is complete
        IF i >= k - 1:

            result.append(nums[deque.front])

    RETURN result

5. Python Implementation

from collections import deque


def max_sliding_window(nums, k):

    dq = deque()
    result = []

    for i in range(len(nums)):

        # Remove elements outside the window
        while dq and dq[0] <= i - k:
            dq.popleft()

        # Remove smaller elements
        while dq and nums[dq[-1]] <= nums[i]:
            dq.pop()

        # Add current index
        dq.append(i)

        # Add maximum when window is complete
        if i >= k - 1:
            result.append(nums[dq[0]])

    return result


# Example
nums = [1, 3, -1, -3, 5, 3, 6, 7]
k = 3

answer = max_sliding_window(nums, k)

print("Array:", nums)
print("Window size:", k)
print("Maximums:", answer)

7. Why Use a Deque?

A brute-force approach finds the maximum separately for every window. That can take O(n × k) time.

The deque approach removes elements that can never become the maximum of the current or any future window.

For example: 

Current window:

[1, 3, -1]

Deque:

[3, -1]

3 is at the front,
so maximum = 3


Next window:

[3, -1, -3]

Deque front is still 3.

Maximum = 3

When 5 enters the window, smaller values such as -1 and -3 are removed from the deque because they cannot be the maximum while 5 remains in the window.

8. Complexity Analysis

Time Complexity

O(n)

Every index is inserted into and removed from the deque at most once.

Space Complexity

O(k)

The deque contains at most k useful indices.
