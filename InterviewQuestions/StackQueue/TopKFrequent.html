Top K Frequent Elements

Problem

Given an integer array, return the k most frequent elements.

The answer may be returned in any order.

Example

Input: nums = [1,1,1,2,2,3], k = 2

Output: [1,2]

Algorithm

  1. Create a frequency map.
  2. Traverse the array and count the occurrence of every element.
  3. Convert the frequency map into key-frequency pairs.
  4. Sort the pairs in descending order of frequency.
  5. Take the first k elements.
  6. Return those elements.

Pseudocode

TOP_K_FREQUENT(nums, k)

    frequency = empty map

    for each num in nums
        frequency[num]++

    pairs = convert frequency to list

    sort pairs by frequency descending

    result = empty list

    for i = 0 to k - 1
        result.push(pairs[i].value)

    return result

C++ Implementation

#include <bits/stdc++.h>
using namespace std;

vector<int> topKFrequent(vector<int>& nums, int k) {

    unordered_map<int, int> freq;

    // Count frequency
    for (int x : nums) {
        freq[x]++;
    }

    // Store pairs
    vector<pair<int, int>> pairs;

    for (auto &p : freq) {
        pairs.push_back({p.second, p.first});
    }

    // Sort by frequency descending
    sort(pairs.begin(), pairs.end(),
        [](const pair<int,int>& a,
           const pair<int,int>& b) {
            return a.first > b.first;
        });

    vector<int> result;

    for (int i = 0; i < k; i++) {
        result.push_back(pairs[i].second);
    }

    return result;
}

Python Implementation

from collections import Counter

def topKFrequent(nums, k):

    # Count frequencies
    frequency = Counter(nums)

    # Sort by frequency
    pairs = sorted(
        frequency.items(),
        key=lambda x: x[1],
        reverse=True
    )

    # Take first k elements
    return [x[0] for x in pairs[:k]]


# Example
nums = [1, 1, 1, 2, 2, 3]
k = 2

print(topKFrequent(nums, k))
# Output: [1, 2]

Complexity Analysis

Time Complexity

O(n + m log m)

n = number of array elements
m = number of unique elements

Space Complexity

O(m)

The frequency map stores each unique element.
