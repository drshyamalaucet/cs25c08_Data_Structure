Longest Consecutive Sequence

Interactive Array Algorithm Visualizer

1. Problem Statement

Given an unsorted array of integers, find the length of the longest sequence of consecutive elements.

The algorithm should run in approximately O(n) time.

Example:

Input:
[100, 4, 200, 1, 3, 2]

Consecutive sequence:
1 → 2 → 3 → 4

Output:
4

4. Algorithm

Step 1 Put every number into a hash set.
Step 2 Pick each number from the set.
Step 3 Check whether the previous number num - 1 exists.
Step 4 If it does not exist, this number is the beginning of a sequence.
Step 5 Keep checking: num + 1, num + 2, etc.
Step 6 Keep track of the longest sequence.

5. Example Walkthrough

Array:
[100, 4, 200, 1, 3, 2]

{100, 4, 200, 1, 3, 2}

99 does not exist

Check 200:

1 → 2 → 3 → 4

Length = 4

6. Pseudocode

function longestConsecutive(nums):

    create a hash set from nums

    longest = 0

    for each num in set:

        if num - 1 is not in set:

            current = num
            length = 1

            while current + 1 is in set:

                current = current + 1
                length = length + 1

            longest = max(longest, length)

    return longest

7. Python Implementation

def longest_consecutive(nums):

    # Store all numbers in a set
    num_set = set(nums)

    longest = 0

    for num in num_set:

        # Start only if num is the beginning
        # of a sequence
        if num - 1 not in num_set:

            current = num
            length = 1

            # Find consecutive numbers
            while current + 1 in num_set:

                current += 1
                length += 1

            longest = max(longest, length)

    return longest


# Example
nums = [100, 4, 200, 1, 3, 2]

result = longest_consecutive(nums)

print(result)

Output:

4

8. Python Code Explanation

The key idea is to use a Python set. Searching for an element in a set takes approximately O(1) average time.

For every number, we first check: 

num - 1 not in num_set

If this is true, then num is the start of a consecutive sequence.

For example: 

1 → 2 → 3 → 4

For 1:
0 does not exist
Therefore 1 is the starting point.

We then repeatedly check: 

2
3
4
5

When 5 is not present, the sequence ends. Its length is 4.

9. Why Use a Hash Set?

A simple solution is to sort the array first. 

sorted(nums)

But sorting requires: 

O(n log n)

The hash-set solution avoids sorting and achieves approximately: 

O(n)

This is why the hash-set approach is commonly used for this problem.

10. Complexity Analysis

Time Complexity O(n)

Each number is processed a constant number of times on average.
Space Complexity O(n)

The hash set stores the numbers.

11. Important Observation

The most important condition is: 

if num - 1 not in num_set:

This ensures that we only start counting from the beginning of a sequence.

For example: 

1 → 2 → 3 → 4

1:
0 does not exist → START

2:
1 exists → don't start

3:
2 exists → don't start

4:
3 exists → don't start

Therefore, the sequence is counted only once rather than repeatedly from every element.
