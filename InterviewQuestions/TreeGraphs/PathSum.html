🌳 Path Sum in a Binary Tree

Interactive Visualization + Pseudocode + Python Implementation

1. Problem Statement

Given the root of a binary tree and an integer targetSum, determine whether the tree has a root-to-leaf path such that the sum of all node values along that path equals the target sum.
Example:

Binary Tree:

        5
      /      \
    4        8
   /          /    \
  11        13    4
  /  \
7    2

Target Sum = 22

Path: 5 → 4 → 11 → 2

5 + 4 + 11 + 2 = 22

Therefore, the answer is True.

3. Algorithm

  1. Start from the root node.
  2. Add the current node's value to the running sum.
  3. If the node is a leaf, compare the sum with targetSum.
  4. If they are equal, return True.
  5. Otherwise, recursively check the left and right subtrees.
  6. If no root-to-leaf path matches, return False.

4. Pseudocode

FUNCTION hasPathSum(root, targetSum):

    IF root is NULL:
        RETURN False

    currentSum = targetSum - root.value

    IF root.left is NULL AND root.right is NULL:
        RETURN currentSum == 0

    RETURN hasPathSum(root.left, currentSum)
           OR
           hasPathSum(root.right, currentSum)

5. Python Implementation

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def hasPathSum(root, targetSum):
    if root is None:
        return False

    targetSum -= root.val

    # Leaf node
    if root.left is None and root.right is None:
        return targetSum == 0

    return (
        hasPathSum(root.left, targetSum)
        or hasPathSum(root.right, targetSum)
    )

6. Iterative Python Implementation

def hasPathSum(root, targetSum):

    if root is None:
        return False

    stack = [(root, root.val)]

    while stack:

        node, current_sum = stack.pop()

        if node.left is None and node.right is None:
            if current_sum == targetSum:
                return True

        if node.right:
            stack.append(
                (node.right, current_sum + node.right.val)
            )

        if node.left:
            stack.append(
                (node.left, current_sum + node.left.val)
            )

    return False

7. Step-by-Step Example

Path 1

5 → 4 → 11 → 7
5 + 4 + 11 + 7 = 27

27 ≠ 22 → Not a valid path.

Path 2

5 → 4 → 11 → 2
5 + 4 + 11 + 2 = 22

22 = 22 → Valid root-to-leaf path.

Important: The path must start at the root and must end at a leaf. A partial path that reaches the target sum at an internal node does not count.

8. Complexity Analysis

Time Complexity

O(N)

In the worst case, every node may need to be visited.

Space Complexity

O(H)

Recursive stack space depends on the height H of the tree.

9. Important Observations

1. Root-to-leaf: The path cannot start from an arbitrary node.
2. Leaf condition: The target sum must be checked when a leaf node is reached.
3. Negative values: The algorithm also works when tree nodes contain negative values.
4. Early termination: Once a valid path is found, the algorithm can immediately return True.
