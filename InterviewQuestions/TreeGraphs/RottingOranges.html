Rotting Oranges

Interactive Multi-Source BFS Visualization

1. Problem Statement

You are given a grid where:

  • 0 = Empty cell
  • 1 = Fresh orange
  • 2 = Rotten orange

Every minute, a fresh orange adjacent to a rotten orange becomes rotten.

Return the minimum number of minutes required until no fresh oranges remain.

If some fresh orange can never become rotten, return -1.

4. Approach – Multi-Source BFS

Step 1 – Initialize Queue

Put every rotten orange into the queue.

Also count the number of fresh oranges.

Step 2 – BFS by Minute

Process all rotten oranges currently in the queue.

Their adjacent fresh oranges become rotten and are added to the queue.

Why BFS?

All initially rotten oranges spread simultaneously. BFS processes oranges level by level, so each BFS level corresponds to exactly one minute.

5. Pseudocode

function orangesRotting(grid):

    queue = empty queue
    fresh = 0
    minutes = 0

    for every cell:

        if cell == 2:
            add cell to queue

        if cell == 1:
            fresh += 1

    while queue is not empty AND fresh > 0:

        size = queue.size()

        repeat size times:

            (r, c) = queue.pop()

            for each of four directions:

                nr = r + dr
                nc = c + dc

                if grid[nr][nc] == 1:

                    grid[nr][nc] = 2

                    fresh -= 1

                    queue.push(nr, nc)

        minutes += 1

    if fresh == 0:
        return minutes

    return -1

6. Python Implementation

from collections import deque


class Solution:

    def orangesRotting(self, grid):

        rows = len(grid)
        cols = len(grid[0])

        queue = deque()
        fresh = 0

        # Find all rotten and fresh oranges
        for r in range(rows):

            for c in range(cols):

                if grid[r][c] == 2:
                    queue.append((r, c))

                elif grid[r][c] == 1:
                    fresh += 1

        minutes = 0

        directions = [
            (1, 0),
            (-1, 0),
            (0, 1),
            (0, -1)
        ]

        # Multi-source BFS
        while queue and fresh > 0:

            size = len(queue)

            for _ in range(size):

                r, c = queue.popleft()

                for dr, dc in directions:

                    nr = r + dr
                    nc = c + dc

                    if (
                        0 <= nr < rows
                        and
                        0 <= nc < cols
                        and
                        grid[nr][nc] == 1
                    ):

                        grid[nr][nc] = 2

                        fresh -= 1

                        queue.append((nr, nc))

            minutes += 1

        return minutes if fresh == 0 else -1


# Example
grid = [
    [2, 1, 1],
    [1, 1, 0],
    [0, 1, 1]
]

solution = Solution()

print(solution.orangesRotting(grid))
# Output: 4

8. When Is the Answer -1?

Consider: 

2 1 0
0 1 0
0 0 0

The fresh oranges connected to the rotten orange can become rotten, but if a fresh orange is separated by empty cells and cannot be reached, it remains fresh.

Therefore:

If BFS finishes and the number of fresh oranges is greater than zero, return -1.

9. Complexity Analysis

O(m × n) Time Complexity

Every cell is processed at most once.

O(m × n) Space Complexity

In the worst case, the BFS queue contains many cells.

4 Directions Neighbor Check

Up, down, left and right.

10. Important Observations

  • All initially rotten oranges must enter the queue before BFS starts.
  • This is called multi-source BFS.
  • Each BFS level represents one minute.
  • Only horizontally and vertically adjacent oranges can rot each other.
  • Empty cells do not participate in the process.
  • The fresh-orange count makes it easy to detect whether all oranges have eventually become rotten.
  • If fresh oranges remain after BFS finishes, the answer is -1.

11. Key Concept: Multi-Source BFS

Ordinary BFS starts from one source. Here, there may be several rotten oranges initially.

All of them are inserted into the queue at the same time: 

Queue initially:

[ Rotten A, Rotten B, Rotten C ]

             ↓
       Multi-Source BFS

Minute 1:
All three sources spread.

Minute 2:
Their newly rotten neighbors spread.

Minute 3:
The next layer spreads.

...

This guarantees that every fresh orange is reached in the minimum possible number of minutes.
