Find Median from Data Stream

Interactive visualization using two heaps

1. Problem Statement

Design a data structure that supports adding integers from a continuous data stream and finding the median of all elements looked at so far.

A median is the middle value when all numbers are sorted. If there are an even number of elements, the median is the average of the two middle values.

Example: Stream = 5, 15, 1, 3

After adding all elements: Sorted order = 1, 3, 5, 15

Median = (3 + 5) / 2 = 4

4. Algorithm

Max Heap

The max heap contains the lower half of the numbers.

Its top element is the largest element in the lower half.

Min Heap

The min heap contains the upper half of the numbers.

Its top element is the smallest element in the upper half.

Balance rule:
  1. The max heap may contain one more element than the min heap.
  2. The min heap may not contain more elements than the max heap.
  3. If the sizes become unbalanced, move the root of one heap to the other.

5. Pseudocode

Initialize maxHeap
Initialize minHeap

function addNum(num):

    if maxHeap is empty OR num <= maxHeap.top:
        insert num into maxHeap
    else:
        insert num into minHeap

    if size(maxHeap) > size(minHeap) + 1:
        move maxHeap.top to minHeap

    if size(minHeap) > size(maxHeap):
        move minHeap.top to maxHeap


function findMedian():

    if size(maxHeap) > size(minHeap):
        return maxHeap.top

    else:
        return (maxHeap.top + minHeap.top) / 2.0

6. Python Implementation

import heapq


class MedianFinder:

    def __init__(self):
        # Max heap implemented using negative values
        self.lower = []

        # Min heap
        self.upper = []

    def addNum(self, num):

        # Add to lower half
        if not self.lower or num <= -self.lower[0]:
            heapq.heappush(self.lower, -num)
        else:
            heapq.heappush(self.upper, num)

        # Balance heaps
        if len(self.lower) > len(self.upper) + 1:
            value = -heapq.heappop(self.lower)
            heapq.heappush(self.upper, value)

        elif len(self.upper) > len(self.lower):
            value = heapq.heappop(self.upper)
            heapq.heappush(self.lower, -value)

    def findMedian(self):

        if len(self.lower) > len(self.upper):
            return -self.lower[0]

        return (-self.lower[0] + self.upper[0]) / 2.0


# Example
mf = MedianFinder()

stream = [5, 15, 1, 3]

for x in stream:
    mf.addNum(x)
    print("Added:", x)
    print("Median:", mf.findMedian())

7. Python Explanation

import heapq

lower = []   # max heap using negative values
upper = []   # min heap

def addNum(num):

    if not lower or num <= -lower[0]:
        heapq.heappush(lower, -num)
    else:
        heapq.heappush(upper, num)

    if len(lower) > len(upper) + 1:
        heapq.heappush(upper, -heapq.heappop(lower))

    if len(upper) > len(lower):
        heapq.heappush(lower, -heapq.heappop(upper))


def findMedian():

    if len(lower) > len(upper):
        return -lower[0]

    return (-lower[0] + upper[0]) / 2

Python's heapq provides a min heap. Therefore, negative values are used to simulate a max heap.

9. Why Use Two Heaps?

Keeping all numbers in a sorted array would make insertion expensive because elements may need to be shifted.

Two heaps divide the data into two approximately equal halves:

  • Max Heap: smaller half
  • Min Heap: larger half

The median can then be obtained directly from the roots of the heaps.

Important: The maximum element of the lower half must always be less than or equal to the minimum element of the upper half.

10. Complexity Analysis

O(log N) Time for addNum()
O(1) Time for findMedian()
O(N) Space

11. Important Observations

  • The two heaps together contain every element seen so far.
  • Their sizes differ by at most one.
  • The max heap stores the lower half.
  • The min heap stores the upper half.
  • If the total number of elements is odd, the larger heap contains the median.
  • If the total number is even, the median is the average of the two heap roots.
  • Duplicate values are handled naturally.
