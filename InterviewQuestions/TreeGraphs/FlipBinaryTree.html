Flip / Invert a Binary Tree

Interactive Binary Tree Mirror Image Visualizer

1. Problem Statement

Given the root of a binary tree, flip the tree so that the left and right subtrees of every node are swapped.

In other words, create the mirror image of the original binary tree.

Example: 

        Original                 Flipped

           4                        4
          / \                      / \
         2   7        →           7   2
        / \ / \                  / \ / \
       1  3 6  9                9  6 3  1

2. Example

Input Tree:

             4
           /   \
          2     7
         / \   / \
        1   3 6   9

Output Tree:

             4
           /   \
          7     2
         / \   / \
        9   6 3   1

Every node has its left and right children exchanged.

4. How the Algorithm Works

  1. Start at the root node.
  2. Recursively flip the left subtree.
  3. Recursively flip the right subtree.
  4. Swap the left and right children of the current node.
  5. Continue until every node has been processed.
Left Child
⇄
Right Child

The important operation at every node is: 

root.left, root.right = root.right, root.left

5. Pseudocode

FUNCTION invertTree(root)

    IF root is NULL
        RETURN NULL

    invertTree(root.left)

    invertTree(root.right)

    TEMP ← root.left
    root.left ← root.right
    root.right ← TEMP

    RETURN root

END FUNCTION

6. Python Implementation

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def invert_tree(root):
    if root is None:
        return None

    # Recursively invert left subtree
    invert_tree(root.left)

    # Recursively invert right subtree
    invert_tree(root.right)

    # Swap left and right children
    root.left, root.right = root.right, root.left

    return root

7. Iterative Python Implementation

The tree can also be flipped using a queue instead of recursion. 

from collections import deque

def invert_tree(root):
    if root is None:
        return None

    queue = deque([root])

    while queue:
        node = queue.popleft()

        # Swap children
        node.left, node.right = node.right, node.left

        if node.left:
            queue.append(node.left)

        if node.right:
            queue.append(node.right)

    return root

8. Explanation

  • A binary tree is flipped by swapping the two children of every node.
  • For a node containing 4, its children 2 and 7 become 7 and 2.
  • The same operation is performed recursively for all descendants.
  • Leaf nodes do not have children, so there is nothing to swap.
  • The final tree is the mirror image of the original tree.

9. Complexity Analysis

Time Complexity

O(n)

Every node is visited exactly once.

Space Complexity

O(h) for the recursive approach.

Here, h is the height of the tree.

For a balanced tree, recursive space is approximately O(log n).

For a completely skewed tree, it can become O(n).

10. Important Observation

The values of the nodes do not change. Only the links between the left and right children are changed.

For example: 

Before:

       1
      / \
     2   3


After:

       1
      / \
     3   2

Therefore, flipping a binary tree is also called inverting or creating the mirror image of the tree.
