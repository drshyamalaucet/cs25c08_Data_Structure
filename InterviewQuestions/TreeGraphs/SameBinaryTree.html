Same Binary Tree

Interactive Structure and Value Comparison Visualizer

1. Problem Statement

Given the roots of two binary trees, determine whether the two trees are structurally identical and contain the same node values.

Two trees are identical only when:

  • The corresponding nodes have the same values.
  • The corresponding left children have the same structure.
  • The corresponding right children have the same structure.

The function should return True if they are identical; otherwise, return False.

2. Example

Tree 1

          1
         / \
        2   3
       / \
      4   5

Tree 2

          1
         / \
        2   3
       / \
      4   5

Both trees have the same structure and the same values.

Output: True

4. Algorithm

  1. Compare the two current nodes.
  2. If both nodes are NULL, they match.
  3. If one node is NULL and the other is not, the trees are structurally different.
  4. If their values are different, the trees are not identical.
  5. Recursively compare their left subtrees.
  6. Recursively compare their right subtrees.
  7. Return true only if all corresponding nodes match.

5. What Must Match?

Condition Result
Both nodes are NULL Match
Only one node is NULL Not identical
Values are different Not identical
Values same + left/right subtrees same Match

6. Pseudocode

FUNCTION isSameTree(p, q)

    IF p is NULL AND q is NULL
        RETURN True

    IF p is NULL OR q is NULL
        RETURN False

    IF p.value != q.value
        RETURN False

    leftSame ← isSameTree(p.left, q.left)

    rightSame ← isSameTree(p.right, q.right)

    RETURN leftSame AND rightSame

END FUNCTION

7. Python Implementation

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def is_same_tree(p, q):

    # Both trees are empty
    if p is None and q is None:
        return True

    # One tree is empty
    if p is None or q is None:
        return False

    # Values are different
    if p.val != q.val:
        return False

    # Compare left and right subtrees
    return (
        is_same_tree(p.left, q.left)
        and
        is_same_tree(p.right, q.right)
    )

8. Iterative Python Implementation

from collections import deque


def is_same_tree(p, q):

    queue = deque([(p, q)])

    while queue:

        node1, node2 = queue.popleft()

        if node1 is None and node2 is None:
            continue

        if node1 is None or node2 is None:
            return False

        if node1.val != node2.val:
            return False

        queue.append((node1.left, node2.left))
        queue.append((node1.right, node2.right))

    return True

This version compares corresponding nodes using Breadth-First Search (BFS).

9. Explanation

Consider the two nodes currently being compared: 

Tree 1                    Tree 2

    2                        2
   / \                      / \
  4   5                    4   5

The values 2, 4, and 5 match and the child structure also matches.

But consider: 

Tree 1                    Tree 2

    2                        2
   /                          \
  4                            4

Both trees contain the same values, but their structures are different. Therefore the answer is False.

10. Important Observation

Checking only the values is not sufficient.

For example: 

Tree 1:       1              Tree 2:       1
             /                              \
            2                                2

Both contain 1 and 2, but the position of node 2 is different.

Therefore they are not structurally identical.

11. Complexity Analysis

Time Complexity

O(n)

Each corresponding pair of nodes is examined at most once.

Space Complexity

O(h)

For the recursive solution, where h is the maximum height of the trees.

In the worst case of a skewed tree, recursive space can become O(n).
