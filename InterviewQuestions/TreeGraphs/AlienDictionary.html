Alien Dictionary

Derive the Alien Alphabet Order using Topological Sorting

1. Problem Statement

You are given a list of words from an alien language. The words are already sorted lexicographically according to the alien language's alphabet.

Determine the order of characters in the alien alphabet.

If the ordering cannot be determined because the input contains an invalid prefix relationship or a cycle, return an empty string.
Example:

words = ["wrt", "wrf", "er", "ett", "rftt"]

Derived order: wertf

6. Key Idea

Compare every pair of adjacent words. Find the first character position where the two words differ.

If:

word1 = "wrt"
word2 = "wrf"

The first difference is:
t vs f

Since "wrt" comes before "wrf":

t → f

Therefore t comes before f in the alien alphabet.

7. Algorithm Steps

  1. Collect every unique character appearing in the words.
  2. Compare each pair of adjacent words.
  3. Find their first different characters.
  4. Add a directed edge from the first character to the second.
  5. Increase the indegree of the second character.
  6. Put all characters with indegree 0 into a queue.
  7. Perform topological sorting.
  8. The resulting sequence is the alien alphabet order.
  9. If not all characters are processed, a cycle exists.

8. Pseudocode

AlienDictionary(words):

    graph = empty adjacency list
    indegree = empty map

    for every word:
        for every character c:
            create c in graph
            indegree[c] = 0

    for i from 0 to words.length - 2:

        word1 = words[i]
        word2 = words[i + 1]

        if word1 is longer than word2
           and word1 starts with word2:

            return ""

        for j from 0 to min(length(word1), length(word2)) - 1:

            if word1[j] != word2[j]:

                u = word1[j]
                v = word2[j]

                if v is not already in graph[u]:

                    graph[u].append(v)
                    indegree[v]++

                break

    queue = all characters whose indegree is 0

    order = []

    while queue is not empty:

        current = queue.pop()

        order.append(current)

        for next in graph[current]:

            indegree[next]--

            if indegree[next] == 0:
                queue.push(next)

    if length(order) != number of unique characters:

        return ""

    return order

9. Python Implementation

from collections import deque

def alien_order(words):

    # Create graph and indegree for every character
    graph = {c: set() for word in words for c in word}
    indegree = {c: 0 for c in graph}

    # Compare adjacent words
    for w1, w2 in zip(words, words[1:]):

        # Invalid prefix case
        if len(w1) > len(w2) and w1.startswith(w2):
            return ""

        for c1, c2 in zip(w1, w2):

            if c1 != c2:

                # Avoid duplicate edges
                if c2 not in graph[c1]:
                    graph[c1].add(c2)
                    indegree[c2] += 1

                break

    # Characters with no prerequisites
    queue = deque(
        c for c in indegree
        if indegree[c] == 0
    )

    order = []

    # Topological sort
    while queue:

        current = queue.popleft()
        order.append(current)

        for nxt in graph[current]:

            indegree[nxt] -= 1

            if indegree[nxt] == 0:
                queue.append(nxt)

    # Cycle detected
    if len(order) != len(graph):
        return ""

    return "".join(order)


# Example
words = [
    "wrt",
    "wrf",
    "er",
    "ett",
    "rftt"
]

print(alien_order(words))

Output

wertf

The exact answer can vary when the input does not uniquely determine the relative order of some characters.

10. Example Walkthrough

Input:

["wrt", "wrf", "er", "ett", "rftt"]

Adjacent comparisons:

1. "wrt" vs "wrf"
First difference: t → f

2. "wrf" vs "er"
First difference: w → e

3. "er" vs "ett"
First difference: r → t

4. "ett" vs "rftt"
First difference: e → r

Therefore the dependency graph contains:

t → f
w → e
r → t
e → r

Topological ordering:
w → e → r → t → f

Final answer:
wertf

11. Important Invalid Case

Consider:

["abc", "ab"]

The second word is a prefix of the first word, but it appears after the first word.

This is impossible in lexicographical ordering.

Therefore the answer is:

""

12. Cycle Detection

Consider dependencies such as: 

a → b
b → c
c → a

No character can be placed first because every character depends on another character.

Therefore topological sorting processes fewer characters than actually exist, indicating a cycle.

In that case the algorithm returns an empty string.

13. Complexity Analysis

Time Complexity

O(C + E + L)

C = number of unique characters
E = number of character relationships
L = total number of characters in all words

Space Complexity

O(C + E)

Space is required for the graph, indegree map, queue and resulting order.

14. Important Observations

  • Only adjacent words need to be compared.
  • Only the first differing character gives a valid ordering constraint.
  • [a,b] in the dependency graph means a must appear before b.
  • Duplicate edges must not increase indegree more than once.
  • A cycle means the alien alphabet order is impossible.
  • An invalid prefix such as ["abc","ab"] must also return an empty string.
  • If multiple characters have indegree 0 simultaneously, more than one valid alphabet ordering may exist.
