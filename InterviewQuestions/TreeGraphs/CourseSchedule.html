Course Schedule II

Find a valid ordering of courses using Topological Sort

1. Problem Statement

There are numCourses courses labeled from 0 to numCourses - 1.

prerequisites[i] = [a, b] means that course b must be completed before course a.

Return an ordering of courses that allows you to finish all courses. If it is impossible because of a cycle, return an empty array.
Example:

numCourses = 4
prerequisites = [[1,0], [2,0], [3,1], [3,2]]

One valid answer is: [0, 1, 2, 3]

5. How the Algorithm Works

  1. Create a directed graph from the prerequisite pairs.
  2. Calculate the indegree of every course.
  3. Courses with indegree 0 have no remaining prerequisites.
  4. Put all indegree-0 courses into a queue.
  5. Remove one course from the queue.
  6. Add it to the final course ordering.
  7. Remove its outgoing edges by decreasing the indegree of its dependent courses.
  8. If a dependent course reaches indegree 0, add it to the queue.
  9. Repeat until the queue becomes empty.
  10. If all courses were processed, the ordering is valid.
  11. If some courses remain, a cycle exists and no valid ordering is possible.

6. Pseudocode

CourseSchedule(numCourses, prerequisites):

    graph = adjacency list
    indegree = array of size numCourses initialized to 0

    for [course, prerequisite] in prerequisites:
        graph[prerequisite].append(course)
        indegree[course]++

    queue = all courses whose indegree is 0
    order = []

    while queue is not empty:

        current = queue.pop()

        order.append(current)

        for nextCourse in graph[current]:

            indegree[nextCourse]--

            if indegree[nextCourse] == 0:
                queue.push(nextCourse)

    if length(order) == numCourses:
        return order

    return []

7. Python Implementation

Using Kahn's Algorithm (BFS)

from collections import deque

def find_order(numCourses, prerequisites):

    graph = [[] for _ in range(numCourses)]
    indegree = [0] * numCourses

    # Build graph
    for course, prerequisite in prerequisites:
        graph[prerequisite].append(course)
        indegree[course] += 1

    # Courses having no prerequisites
    queue = deque()

    for course in range(numCourses):
        if indegree[course] == 0:
            queue.append(course)

    order = []

    # Topological sorting
    while queue:

        current = queue.popleft()
        order.append(current)

        for next_course in graph[current]:

            indegree[next_course] -= 1

            if indegree[next_course] == 0:
                queue.append(next_course)

    # Cycle detected
    if len(order) != numCourses:
        return []

    return order


# Example
numCourses = 4
prerequisites = [
    [1, 0],
    [2, 0],
    [3, 1],
    [3, 2]
]

print(find_order(numCourses, prerequisites))

Possible Output

[0, 1, 2, 3]

There can be more than one correct ordering. For example, [0, 2, 1, 3] is also valid for the same prerequisites.

9. Complexity Analysis

Time Complexity

O(V + E)

V = number of courses
E = number of prerequisite relationships

Space Complexity

O(V + E)

Graph, indegree array, queue and result array require additional memory.

10. Important Observations

  • A prerequisite relationship forms a directed edge.
  • [a,b] means b → a.
  • Indegree represents the number of prerequisites still remaining.
  • An indegree of 0 means the course is currently available.
  • A valid course schedule is a topological ordering.
  • A directed cycle makes it impossible to finish all courses.
  • There may be multiple valid course orderings.
