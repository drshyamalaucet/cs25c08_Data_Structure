Word Search II

Find all dictionary words in a character board using Trie + DFS Backtracking

1. Problem Statement

Given an m × n board of characters and a list of strings words, return all words that can be constructed from letters of sequentially adjacent cells.

A word can be formed by moving: up, down, left, or right. Diagonal movement is not allowed.

The same cell cannot be used more than once while constructing one word.
Example:

Board: 
[
  ["o","a","a","n"],
  ["e","t","a","e"],
  ["i","h","k","r"],
  ["i","f","l","v"]
]
Words: ["oath","pea","eat","rain"]

Output: ["oath","eat"]

7. How the Algorithm Works

  1. Insert every dictionary word into a Trie.
  2. Start DFS from every cell of the board.
  3. Follow adjacent cells while the current sequence is a Trie prefix.
  4. When a Trie node marks the end of a word, add that word to the result.
  5. Mark the current board cell as visited.
  6. Explore its four neighbors.
  7. Backtrack and make the cell available again.
  8. Continue until all possible paths have been explored.
  9. Return all discovered words.
Why use a Trie?

Without a Trie, we may repeatedly construct strings that cannot possibly be dictionary words. The Trie allows us to immediately stop DFS whenever the current sequence is not a valid prefix.

8. Pseudocode

WordSearch(board, words):

    Build a Trie using all words

    result = empty set

    for every cell (r, c):

        DFS(r, c, trieRoot, "")

    return result


DFS(r, c, node, currentWord):

    if cell is outside board:
        return

    if cell is already visited:
        return

    character = board[r][c]

    if character is not a child of node:
        return

    nextNode = node.children[character]

    currentWord += character

    if nextNode represents a complete word:
        add currentWord to result

    mark board[r][c] as visited

    DFS(r+1, c, nextNode, currentWord)
    DFS(r-1, c, nextNode, currentWord)
    DFS(r, c+1, nextNode, currentWord)
    DFS(r, c-1, nextNode, currentWord)

    unmark board[r][c]

9. Python Implementation

class TrieNode:

    def __init__(self):
        self.children = {}
        self.word = None


def find_words(board, words):

    root = TrieNode()

    # Build Trie
    for word in words:

        node = root

        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()

            node = node.children[ch]

        node.word = word

    rows = len(board)
    cols = len(board[0])

    result = []

    def dfs(r, c, node):

        if r < 0 or r >= rows or c < 0 or c >= cols:
            return

        ch = board[r][c]

        if ch == "#":
            return

        if ch not in node.children:
            return

        next_node = node.children[ch]

        # Complete word found
        if next_node.word is not None:
            result.append(next_node.word)

            # Prevent duplicate output
            next_node.word = None

        board[r][c] = "#"

        dfs(r + 1, c, next_node)
        dfs(r - 1, c, next_node)
        dfs(r, c + 1, next_node)
        dfs(r, c - 1, next_node)

        board[r][c] = ch

    for r in range(rows):
        for c in range(cols):
            dfs(r, c, root)

    return result


# Example
board = [
    ["o","a","a","n"],
    ["e","t","a","e"],
    ["i","h","k","r"],
    ["i","f","l","v"]
]

words = ["oath", "pea", "eat", "rain"]

print(find_words(board, words))

Output

['oath', 'eat']

11. DFS Backtracking

Suppose the current path is: 

o → a → t

The algorithm temporarily marks these cells as visited. After exploring the neighbors of t, it returns to a and then o.

This process is called backtracking. It allows the same board cell to be reused for a different word, but never twice in the same path.

12. Complexity Analysis

Trie Construction

O(L)

L = total number of characters in all dictionary words.

DFS Search

Worst case can be large because many board paths may be explored. The Trie significantly prunes paths that are not dictionary prefixes.

Space Complexity

O(L) for the Trie plus DFS/backtracking space.

Practical Advantage

The Trie avoids exploring paths that cannot form any dictionary word.

13. Important Observations

  • Movement is only up, down, left, right.
  • Diagonal movement is not allowed.
  • A board cell cannot be reused within the same word.
  • The Trie stores prefixes as well as complete words.
  • DFS explores possible paths.
  • Backtracking restores each cell after exploration.
  • Using a set or clearing the Trie word prevents duplicate results.
  • The output order does not necessarily need to match the input word order.

14. Why Trie + DFS?

Approach Idea Main Issue
DFS for every word Search the board separately for every dictionary word. Repeated board traversal.
Trie + DFS Search all words simultaneously using shared prefixes. Trie requires additional memory.
