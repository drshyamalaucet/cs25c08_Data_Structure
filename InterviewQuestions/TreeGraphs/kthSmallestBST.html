🌳 Kth Smallest Element in a BST

Interactive Inorder Traversal + Pseudocode + Python Implementation

1. Problem Statement

Given the root of a Binary Search Tree and an integer k, return the kth smallest value in the tree.
Example BST:
5 / \ 3 7 / \ / \ 2 4 6 8 / 1
Inorder traversal: 1, 2, 3, 4, 5, 6, 7, 8

If k = 3:
3rd smallest = 3

2. Key BST Property

In a Binary Search Tree, an inorder traversal visits nodes in ascending order.
Inorder = Left → Root → Right
1 2 3 4 5 6 7 8

Therefore, the kth visited node during inorder traversal is the kth smallest element.

4. Algorithm

  1. Perform an inorder traversal of the BST.
  2. Visit the left subtree first.
  3. When a node is visited, increment the counter.
  4. If the counter equals k, that node is the kth smallest value.
  5. Stop the traversal.

5. Pseudocode

FUNCTION kthSmallest(root, k):

    stack = empty stack
    current = root

    WHILE current is not NULL OR stack is not empty:

        WHILE current is not NULL:
            PUSH current into stack
            current = current.left

        current = POP stack

        k = k - 1

        IF k == 0:
            RETURN current.value

        current = current.right

    RETURN -1

6. Python Implementation – Iterative

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def kthSmallest(root, k):

    stack = []
    current = root

    while current or stack:

        # Go as far left as possible
        while current:
            stack.append(current)
            current = current.left

        # Visit node
        current = stack.pop()

        k -= 1

        if k == 0:
            return current.val

        # Explore right subtree
        current = current.right

    return -1

7. Python Implementation – Recursive

def kthSmallest(root, k):

    result = []

    def inorder(node):

        if node is None:
            return

        inorder(node.left)

        result.append(node.val)

        inorder(node.right)

    inorder(root)

    return result[k - 1]
The recursive version is easy to understand, but it stores the inorder traversal. The iterative version can stop as soon as the kth element is found.

9. Complexity Analysis

Time Complexity

O(H + k)

where H is the height of the BST. In the worst case, this becomes O(N).

Space Complexity

O(H)

The stack contains nodes along the current root-to-leaf path.

10. Important Observations

1. BST ordering: Inorder traversal produces values in sorted ascending order.
2. 1-indexed: The smallest element corresponds to k = 1.
3. Early stopping: Once the counter reaches k, no additional nodes need to be visited.
4. No sorting required: We do not need to extract all values and sort them because the BST already provides sorted order through inorder traversal.
5. Balanced BST: For a balanced BST, the height H is approximately log N.
