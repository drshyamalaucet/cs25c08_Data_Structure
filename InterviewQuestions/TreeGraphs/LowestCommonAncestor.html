🌳 Lowest Common Ancestor in a BST

Interactive Visualization + Pseudocode + Python Implementation

1. Problem Statement

Given the root of a Binary Search Tree (BST) and two nodes p and q, find their Lowest Common Ancestor (LCA).
Example BST:

6 / \ 2 8 / \ / \ 0 4 7 9 / \ 3 5
p = 2, q = 8

Since 2 is smaller than 6 and 8 is greater than 6, they lie on different sides of 6.

Therefore: LCA(2, 8) = 6

2. Key BST Property

For every node in a Binary Search Tree:

Left subtree: values smaller than the node.
Right subtree: values greater than the node.
if p < root AND q < root → move LEFT
if p > root AND q > root → move RIGHT
otherwise → current root is the LCA

4. Algorithm

  1. Start at the root.
  2. Compare p and q with the current node.
  3. If both p and q are smaller, move to the left subtree.
  4. If both p and q are larger, move to the right subtree.
  5. Otherwise, the current node is the Lowest Common Ancestor.

5. Pseudocode

FUNCTION lowestCommonAncestor(root, p, q):

    current = root

    WHILE current is not NULL:

        IF p < current.value AND q < current.value:

            current = current.left

        ELSE IF p > current.value AND q > current.value:

            current = current.right

        ELSE:

            RETURN current

    RETURN NULL

6. Python Implementation

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def lowestCommonAncestor(root, p, q):

    current = root

    while current:

        if p.val < current.val and q.val < current.val:
            current = current.left

        elif p.val > current.val and q.val > current.val:
            current = current.right

        else:
            return current

    return None

7. Recursive Python Implementation

def lowestCommonAncestor(root, p, q):

    if p.val < root.val and q.val < root.val:
        return lowestCommonAncestor(root.left, p, q)

    if p.val > root.val and q.val > root.val:
        return lowestCommonAncestor(root.right, p, q)

    return root

8. Step-by-Step Example

Find LCA of p = 2 and q = 8

Current = 6

p = 2 < 6 and q = 8 > 6.

They are on opposite sides of 6.

Therefore LCA = 6

Another Example: p = 3, q = 5

Current = 6

Both 3 and 5 are smaller than 6. Move left.

Current = 2

Both 3 and 5 are greater than 2. Move right.

Current = 4

3 < 4 and 5 > 4. Therefore:

LCA(3, 5) = 4

9. Complexity Analysis

Time Complexity

O(h)

where h is the height of the BST.

For a balanced BST, this is approximately O(log N).

Space Complexity

O(1)

for the iterative implementation.

The recursive implementation uses O(h) call-stack space.

10. Important Observations

Observation 1: The algorithm takes advantage of the BST ordering property.
Observation 2: If both nodes are smaller than the current node, the LCA must be in the left subtree.
Observation 3: If both nodes are larger than the current node, the LCA must be in the right subtree.
Observation 4: If one node is on each side, or the current node equals p or q, the current node is the LCA.
Observation 5: This efficient approach specifically relies on the tree being a Binary Search Tree. A general binary tree requires a different approach.
