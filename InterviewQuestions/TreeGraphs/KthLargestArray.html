🔢 K-th Largest Element in an Unsorted Array

Interactive Quickselect Visualization + Python Implementation

1. Problem Statement

Given an unsorted array of integers, find the k-th largest element.
Important: The answer is based on sorted order, and the element does not have to be distinct.

Example:
nums = [3, 2, 1, 5, 6, 4]
For:
k = 2
Sort in descending order:
6, 5, 4, 3, 2, 1
Therefore:
2nd largest = 5
Duplicates count. For example, in [3, 2, 3, 1, 2, 4, 5, 5, 6], the 4th largest element is 5, because the sorted descending sequence is 6, 5, 5, 4, 3, 3, 2, 2, 1.

3. Convert K-th Largest to K-th Smallest Position

Quickselect is normally described using a target index in ascending order.

targetIndex = n - k

For:

nums = [3, 2, 1, 5, 6, 4]
n = 6
k = 2
targetIndex = 6 - 2 = 4

The element at index 4 in the sorted array is 5.

4. Quickselect Algorithm

  1. Convert k-th largest into an ascending target index: n - k.
  2. Choose a pivot.
  3. Partition the array around the pivot.
  4. If the pivot reaches the target index, we have the answer.
  5. If the target index is smaller, continue on the left.
  6. If the target index is larger, continue on the right.

5. Pseudocode – Quickselect

FUNCTION findKthLargest(nums, k):

    target = length(nums) - k

    RETURN quickSelect(nums, 0, length(nums) - 1, target)


FUNCTION quickSelect(nums, left, right, target):

    IF left == right:
        RETURN nums[left]

    pivotIndex = partition(nums, left, right)

    IF pivotIndex == target:
        RETURN nums[pivotIndex]

    ELSE IF target < pivotIndex:
        RETURN quickSelect(
            nums, left, pivotIndex - 1, target
        )

    ELSE:
        RETURN quickSelect(
            nums, pivotIndex + 1, right, target
        )

6. Python Implementation – Quickselect

def findKthLargest(nums, k):

    target = len(nums) - k

    def quickselect(left, right):

        pivot = nums[right]
        store_index = left

        for i in range(left, right):

            if nums[i] <= pivot:
                nums[store_index], nums[i] = \
                    nums[i], nums[store_index]

                store_index += 1

        nums[store_index], nums[right] = \
            nums[right], nums[store_index]

        if store_index == target:
            return nums[store_index]

        elif store_index > target:
            return quickselect(left, store_index - 1)

        else:
            return quickselect(store_index + 1, right)

    return quickselect(0, len(nums) - 1)

7. Simple Python Solution Using Sorting

def findKthLargest(nums, k):

    nums.sort(reverse=True)

    return nums[k - 1]
This is the easiest solution to understand. It explicitly sorts the array in descending order and returns the element at position k - 1.

8. Python Solution Using a Min-Heap

import heapq

def findKthLargest(nums, k):

    heap = []

    for num in nums:

        heapq.heappush(heap, num)

        if len(heap) > k:
            heapq.heappop(heap)

    return heap[0]

The heap stores only the k largest elements encountered so far. The smallest of those k elements is the k-th largest overall.

10. Complexity Analysis

Sorting

Time: O(N log N)
Space: O(1) to O(N), depending on sorting implementation

Quickselect

Average Time: O(N)
Worst Time: O(N²)
Extra Space: O(1) for iterative partitioning

Min-Heap

Time: O(N log K)
Space: O(K)

11. Important Observations

1. Duplicates are included. The problem asks for the k-th element in sorted order, not the k-th distinct element.
2. k is 1-indexed. k = 1 means the largest element.
3. Conversion: K-th largest corresponds to index N - K in ascending zero-based order.
4. Quickselect: It does not completely sort the array. It only determines which partition contains the target.
5. Choosing a good pivot helps Quickselect achieve its expected linear-time behavior.
