Maximum Depth of a Binary Tree

Find the Number of Nodes Along the Longest Root-to-Leaf Path

1. Problem Statement

Given the root of a binary tree, find the number of nodes along the longest path from the root node down to the farthest leaf node.

This value is called the maximum depth or maximum height of the binary tree.

Maximum Depth = 1 + max(Depth of Left Subtree, Depth of Right Subtree)

2. Example

              3
             / \
            9  20
               / \
              15  7

The longest root-to-leaf path is:

3 → 20 → 15

Number of nodes = 3

Therefore: Maximum Depth = 3

4. Algorithm

  1. If the current node is NULL, its depth is 0.
  2. Recursively calculate the maximum depth of the left subtree.
  3. Recursively calculate the maximum depth of the right subtree.
  4. Select the larger of the two depths.
  5. Add 1 for the current node.
  6. Return the resulting depth.

5. Recursive Formula

depth(root) = 1 + max(depth(root.left), depth(root.right))

Base case:

depth(NULL) = 0

The 1 represents the current node.

6. Pseudocode

FUNCTION maxDepth(root)

    IF root is NULL
        RETURN 0

    leftDepth ← maxDepth(root.left)

    rightDepth ← maxDepth(root.right)

    RETURN 1 + MAX(leftDepth, rightDepth)

END FUNCTION

7. Python Implementation

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def max_depth(root):

    if root is None:
        return 0

    left_depth = max_depth(root.left)
    right_depth = max_depth(root.right)

    return 1 + max(left_depth, right_depth)

8. Iterative Python Implementation — BFS

We can also calculate the maximum depth level by level using a queue. 

from collections import deque


def max_depth(root):

    if root is None:
        return 0

    queue = deque([root])
    depth = 0

    while queue:

        level_size = len(queue)
        depth += 1

        for _ in range(level_size):

            node = queue.popleft()

            if node.left:
                queue.append(node.left)

            if node.right:
                queue.append(node.right)

    return depth

9. Explanation

Consider the following tree: 

              3
             / \
            9  20
               / \
              15  7

There are two main paths:

  • 3 → 9 = 2 nodes
  • 3 → 20 → 15 = 3 nodes
  • 3 → 20 → 7 = 3 nodes

Therefore, the longest path contains 3 nodes.

10. Depth-First Search Idea

The recursive solution uses Depth-First Search (DFS).

At every node, the algorithm travels down both subtrees and determines which subtree has the greater depth. 

                    3
                   / \
                  9  20
                     / \
                    15  7

                  ↓

        depth(3)
          = 1 + max(depth(9), depth(20))

          = 1 + max(1, 2)

          = 3

11. Complexity Analysis

Time Complexity

O(n)

Every node is visited exactly once.

Space Complexity

O(h)

For the recursive DFS solution, where h is the height of the tree.

In the worst case, a completely skewed tree has O(n) recursion depth.

For a balanced tree, the recursion depth is approximately O(log n).

12. Important Observation

The question asks for the number of nodes in the longest path, not the number of edges. 

        1
       / \
      2   3
     /
    4

Longest path: 1 → 2 → 4

Number of nodes = 3

Number of edges = 2

Therefore, the maximum depth is 3.
