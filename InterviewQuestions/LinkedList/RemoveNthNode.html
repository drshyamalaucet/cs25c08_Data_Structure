Remove the N-th Node From the End

Singly Linked List — Two Pointer Technique

1. Problem Statement

Given the head of a singly linked list, remove the n-th node from the end of the list and return the head of the modified list.

Example


Input:

1 → 2 → 3 → 4 → 5 → NULL

n = 2

The 2nd node from the end is 4. 


Output:

1 → 2 → 3 → 5 → NULL

3. Main Idea

We use two pointers called fast and slow.

  1. Create a dummy node before the head.
  2. Place both fast and slow at the dummy node.
  3. Move fast forward by n + 1 positions.
  4. Move both fast and slow one position at a time.
  5. When fast reaches the end, slow is immediately before the node that must be deleted.
  6. Skip the target node using: 

slow.next = slow.next.next
  • Return dummy.next.

    • 4. Pseudocode

    
REMOVE_NTH_FROM_END(head, n)

    dummy ← new Node(0)
    dummy.next ← head

    fast ← dummy
    slow ← dummy

    REPEAT n + 1 times
        fast ← fast.next

    WHILE fast ≠ NULL
        fast ← fast.next
        slow ← slow.next

    slow.next ← slow.next.next

    RETURN dummy.next

    6. Python Implementation

    
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None


def remove_nth_from_end(head, n):

    # Dummy node handles deletion of the head
    dummy = Node(0)
    dummy.next = head

    slow = dummy
    fast = dummy

    # Move fast n + 1 positions
    for _ in range(n + 1):
        fast = fast.next

    # Move both pointers
    while fast is not None:
        fast = fast.next
        slow = slow.next

    # Remove the n-th node from the end
    slow.next = slow.next.next

    return dummy.next


def display(head):

    current = head

    while current is not None:
        print(current.data, end=" -> ")
        current = current.next

    print("None")


# Create linked list
head = Node(1)
head.next = Node(2)
head.next.next = Node(3)
head.next.next.next = Node(4)
head.next.next.next.next = Node(5)


print("Original List:")
display(head)

n = 2

head = remove_nth_from_end(head, n)

print("After Removing", n, "th Node From End:")
display(head)

    7. Explanation of Python Code

    Dummy Node

    A dummy node is placed before the original head: 

    
dummy → head

    This makes the algorithm easier when the node to be removed is the first node of the list.

    Fast Pointer

    The fast pointer is moved n + 1 positions ahead. This creates a gap of n nodes between fast and slow.

    Move Both Pointers

    
while fast is not None:
    fast = fast.next
    slow = slow.next

    When fast reaches the end, slow is positioned immediately before the node that needs to be removed.

    Delete the Node

    
slow.next = slow.next.next

    This bypasses the target node. The target node is no longer connected to the linked list.

    Return the Head

    
return dummy.next

    The modified head is returned.

    9. Complexity Analysis

    Time Complexity
    O(n)

    The list is traversed once.

    Space Complexity
    O(1)

    Only pointers are used.

    Technique
    Two Pointers

    Fast and slow pointers.

    10. Key Points to Remember

    • Use a dummy node before the head.
    • Move fast n + 1 positions first.
    • Move fast and slow together until fast becomes NULL.
    • Slow will point to the node immediately before the target.
    • Delete the node using: slow.next = slow.next.next
    • Return dummy.next.
    • The algorithm works even when the head itself must be removed.
    • Time complexity is O(n).
    • Space complexity is O(1).
