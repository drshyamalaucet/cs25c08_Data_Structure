Find the Middle Node

Singly Linked List — Slow & Fast Pointer Technique

1. Problem Statement

Given the head of a singly linked list, return the middle node. If the list contains two middle nodes, return the second middle node.

Odd Number of Nodes


10 → 20 → 30 → 40 → 50 → NULL

Middle Node = 30

Even Number of Nodes


10 → 20 → 30 → 40 → 50 → 60 → NULL

Middle Nodes = 30 and 40

Return = 40
(second middle node)

2. Interactive Visualization

The algorithm uses two pointers:

  • Slow pointer: moves one node at a time.
  • Fast pointer: moves two nodes at a time.
SLOW — moves 1 step FAST — moves 2 steps MIDDLE — answer
Ready. Click "Next Step" to start.
Initial State: Both slow and fast pointers start at the head node.

3. Algorithm

  1. Initialize slow = head.
  2. Initialize fast = head.
  3. Move slow by one node: slow = slow.next.
  4. Move fast by two nodes: fast = fast.next.next.
  5. Continue while fast != None and fast.next != None.
  6. When the loop ends, slow points to the middle node.
  7. Return slow.

4. Pseudocode


FIND_MIDDLE(head)

    slow ← head
    fast ← head

    WHILE fast ≠ NULL
          AND fast.next ≠ NULL

        slow ← slow.next
        fast ← fast.next.next

    RETURN slow

6. Python Implementation


class Node:
    def __init__(self, data):
        self.data = data
        self.next = None


def middle_node(head):

    slow = head
    fast = head

    while fast is not None and fast.next is not None:

        # Move slow by one node
        slow = slow.next

        # Move fast by two nodes
        fast = fast.next.next

    return slow


def display(head):

    current = head

    while current is not None:
        print(current.data, end=" -> ")
        current = current.next

    print("None")


# Create linked list
head = Node(10)
head.next = Node(20)
head.next.next = Node(30)
head.next.next.next = Node(40)
head.next.next.next.next = Node(50)
head.next.next.next.next.next = Node(60)


print("Linked List:")
display(head)


# Find middle
middle = middle_node(head)

print("Middle Node:", middle.data)

Middle Node: 40

7. Explanation of Python Code

Node Class

The Node class represents one node of the linked list. Each node contains:

  • data — stores the value.
  • next — points to the next node.

Slow Pointer

The slow pointer moves one node at a time: 


slow = slow.next

Fast Pointer

The fast pointer moves two nodes at a time: 


fast = fast.next.next

Why Does It Work?

Because fast moves twice as quickly as slow, fast reaches the end when slow has travelled approximately half of the list. Therefore, slow is positioned at the middle.

8. Why Does It Return the Second Middle?

Consider an even-sized list: 


10 → 20 → 30 → 40 → 50 → 60

There are two middle nodes: 


10 → 20 → [30] → [40] → 50 → 60
             ↑      ↑
          first    second
          middle   middle

Since both pointers start at the head and the loop moves slow before checking the final position, the slow pointer ends at 40. Thus the algorithm returns the second middle node.

9. Complexity Analysis

Time Complexity
O(n)

The list is traversed once.

Space Complexity
O(1)

Only two pointers are used.

Technique
Two Pointers

Slow and fast pointers.

10. Key Points

  • Use the slow and fast pointer technique.
  • Slow moves one step at a time.
  • Fast moves two steps at a time.
  • When fast reaches the end, slow is at the middle.
  • For an even-length list, this implementation returns the second middle node.
  • No extra array or list is required.
  • Time complexity is O(n).
  • Space complexity is O(1).
