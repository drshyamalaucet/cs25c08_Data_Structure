Reverse a Singly Linked List

In-Place Reversal with Step-by-Step Visualization

1. Problem Statement

Given the head of a singly linked list, reverse the list in place and return the new head node.

Example: 


Original:
10 → 20 → 30 → 40 → NULL

Reversed:
40 → 30 → 20 → 10 → NULL

The important idea is to change each node's next pointer so that it points to the previous node.

3. Algorithm

  1. Initialize prev = None.
  2. Set current = head.
  3. Save the next node: next_node = current.next.
  4. Reverse the pointer: current.next = prev.
  5. Move prev to current.
  6. Move current to next_node.
  7. Repeat until current is None.
  8. Return prev as the new head.

4. Pseudocode


REVERSE(head)

    prev ← NULL
    current ← head

    WHILE current ≠ NULL

        next_node ← current.next

        current.next ← prev

        prev ← current

        current ← next_node

    RETURN prev

6. Python Implementation


class Node:
    def __init__(self, data):
        self.data = data
        self.next = None


def reverse_list(head):
    prev = None
    current = head

    while current is not None:

        # Save the next node
        next_node = current.next

        # Reverse the current node's pointer
        current.next = prev

        # Move prev forward
        prev = current

        # Move current forward
        current = next_node

    # prev is the new head
    return prev


def display(head):
    current = head

    while current is not None:
        print(current.data, end=" -> ")
        current = current.next

    print("None")


# Create linked list
head = Node(10)
head.next = Node(20)
head.next.next = Node(30)
head.next.next.next = Node(40)

print("Original List:")
display(head)

# Reverse the list
head = reverse_list(head)

print("Reversed List:")
display(head)

Output


Original List:
10 -> 20 -> 30 -> 40 -> None

Reversed List:
40 -> 30 -> 20 -> 10 -> None

7. Explanation of the Python Code

prev stores the previous node. Initially there is no previous node, so it is set to None.

current points to the node currently being processed.

next_node temporarily stores the next node. This is essential because changing current.next without saving the next node could cause the remaining list to be lost.

The statement: 


current.next = prev

reverses the direction of the link.

Finally, when current becomes None, prev points to the first node of the reversed list. Therefore, prev is returned as the new head.

8. Complexity Analysis

Time Complexity
O(n)

Each node is visited once.

Space Complexity
O(1)

Only three pointers are used.

Technique
In-Place

No new nodes are created.

9. Key Points to Remember

  • A singly linked list can only move forward using the next pointer.
  • Always save current.next before changing it.
  • current.next = prev performs the actual reversal.
  • prev becomes the new head after the loop.
  • The algorithm uses constant extra space.
