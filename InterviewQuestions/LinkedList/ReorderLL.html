Reorder a Singly Linked List

Problem:
Given a singly linked list L₀ → L₁ → ... → Lₙ₋₁ → Lₙ, reorder it as: L₀ → Lₙ → L₁ → Lₙ₋₁ → L₂ → ...

3. Algorithm

  1. Use slow and fast pointers to find the middle of the list.
  2. Split the list into two halves.
  3. Reverse the second half.
  4. Merge the first and reversed second halves alternately.

4. Pseudocode

REORDER_LIST(head)

1. if head is NULL or head.next is NULL
       return

2. Find middle using slow and fast pointers

3. second = slow.next
   slow.next = NULL

4. Reverse second half

5. first = head

6. while second is not NULL
       temp1 = first.next
       temp2 = second.next

       first.next = second
       second.next = temp1

       first = temp1
       second = temp2

7. return head

5. Python Implementation

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None


def reorder_list(head):

    if head is None or head.next is None:
        return

    # Step 1: Find middle
    slow = head
    fast = head

    while fast.next is not None and fast.next.next is not None:
        slow = slow.next
        fast = fast.next.next

    # Step 2: Split into two halves
    second = slow.next
    slow.next = None

    # Step 3: Reverse second half
    prev = None

    while second is not None:
        next_node = second.next
        second.next = prev
        prev = second
        second = next_node

    second = prev

    # Step 4: Merge alternately
    first = head

    while second is not None:

        temp1 = first.next
        temp2 = second.next

        first.next = second
        second.next = temp1

        first = temp1
        second = temp2

# 1 → 2 → 3 → 4 → 5 → 6

# Result:
# 1 → 6 → 2 → 5 → 3 → 4
