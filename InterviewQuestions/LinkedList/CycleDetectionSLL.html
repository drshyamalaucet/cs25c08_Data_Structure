Linked List Cycle Detection

Problem:
Determine whether a singly linked list contains an internal loop, where a node points back to a previously visited node.

We use Floyd's Cycle Detection Algorithm, also called the Tortoise and Hare Algorithm.

3. Algorithm Explanation

  1. Initialize slow and fast to the head.
  2. Move slow one node at a time.
  3. Move fast two nodes at a time.
  4. If slow == fast, a cycle exists.
  5. If fast reaches NULL, the linked list has no cycle.

4. Pseudocode

HAS_CYCLE(head)

1. slow ← head
2. fast ← head

3. WHILE fast ≠ NULL AND fast.next ≠ NULL

       slow ← slow.next

       fast ← fast.next.next

       IF slow = fast
           RETURN TRUE

4. RETURN FALSE

5. How Slow and Fast Pointers Work

Slow Pointer

The slow pointer moves exactly one node during every iteration.

Example: 1 → 2 → 3 → 4

Fast Pointer

The fast pointer moves two nodes during every iteration.

Example: 1 → 3 → 5 → ...

Why Does It Detect a Cycle?

If there is a cycle, the fast pointer eventually catches the slow pointer inside the loop.

If there is no cycle, fast eventually reaches NULL.

7. Python Implementation

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None


def has_cycle(head):

    slow = head
    fast = head

    while fast is not None and fast.next is not None:

        # Slow moves one step
        slow = slow.next

        # Fast moves two steps
        fast = fast.next.next

        # They meet inside the cycle
        if slow == fast:
            return True

    # Fast reached the end
    return False

#
# 1 → 2 → 3 → 4 → 5

#         |_________|

8. Example: List With a Cycle

Consider:

1 → 2 → 3 → 4 → 5

Suppose node 5 points back to node 3.

3 → 4 → 5
↑_____↓

The sequence becomes:

3 → 4 → 5 → 3 → 4 → 5 → ...

Therefore, the list contains a cycle.

9. Example: List Without a Cycle

1 → 2 → 3 → 4 → 5 → NULL

Here, there is no pointer back to an earlier node. Eventually the fast pointer reaches NULL.

Therefore: No Cycle

10. Complexity Analysis

Time

O(n)

Each node is visited a constant number of times.

Space

O(1)

Only slow and fast pointers are used.

Technique

Floyd's Algorithm

Tortoise and Hare

11. Key Points

  • slow moves one node.
  • fast moves two nodes.
  • If slow and fast meet, a cycle exists.
  • If fast reaches NULL, there is no cycle.
  • The algorithm uses O(1) extra space.
  • It does not modify the linked list.
