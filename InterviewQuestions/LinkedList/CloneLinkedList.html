Clone a Linked List with Random Pointer

Problem:

Given a linked list where every node contains:

  • A value
  • A next pointer
  • A random pointer

The random pointer may point to any node in the list or may be NULL.

Create a deep copy of the complete linked list.

3. Three Phases of Deep Copy

Phase 1

Insert Clone Nodes

Create a clone of every original node and insert the clone immediately after the original node.

Original:
1 → 2 → 3 → 4

After inserting clones:
1 → 1' → 2 → 2' → 3 → 3' → 4 → 4'

Phase 2

Assign Random Pointers

For every original node, its clone's random pointer can be found using: 

clone.random = original.random.next

This works because every clone is located immediately after its corresponding original node.

Phase 3

Separate the Two Lists

Finally, separate the interleaved original and cloned nodes.

Original:
1 → 2 → 3 → 4

Clone:
1' → 2' → 3' → 4'

8. Python Implementation

class Node:
    def __init__(self, val):
        self.val = val
        self.next = None
        self.random = None


def copy_random_list(head):

    if head is None:
        return None

    # -------------------------------------------------
    # Step 1: Insert cloned nodes
    # -------------------------------------------------

    current = head

    while current is not None:

        clone = Node(current.val)

        clone.next = current.next

        current.next = clone

        current = clone.next


    # -------------------------------------------------
    # Step 2: Assign random pointers
    # -------------------------------------------------

    current = head

    while current is not None:

        if current.random is not None:

            current.next.random = current.random.next

        current = current.next.next


    # -------------------------------------------------
    # Step 3: Separate original and cloned lists
    # -------------------------------------------------

    current = head

    clone_head = head.next

    while current is not None:

        clone = current.next

        current.next = clone.next

        if clone.next is not None:
            clone.next = clone.next.next

        current = current.next


    return clone_head

9. Why Is This a Deep Copy?

A deep copy creates new nodes.

The cloned nodes contain the same values as the original nodes, but they do not share node objects with the original list.

For example:

Original: 1 → 2 → 3

Clone: 1' → 2' → 3'

The clone's random pointers point only to cloned nodes. They never point back to the original nodes.

10. Why Does random.next Work?

Suppose:

Original node A has random pointer to C.

After Phase 1:

A → A' → B → B' → C → C'

Therefore: 

A.random = C

C.next = C'

A'.random = A.random.next

A'.random = C'

So the clone's random pointer correctly points to the clone of C.

11. Complexity Analysis

Time Complexity

O(n)

Each node is processed a constant number of times.

Extra Space

O(1)

Ignoring the space required for the cloned list.

Number of Passes

3

Create → Random → Separate

12. Key Points

  • Every original node gets exactly one clone.
  • The clone is temporarily inserted after its original node.
  • Random pointers can point to any node or NULL.
  • The expression original.random.next gives the corresponding cloned node.
  • The original and cloned lists are separated at the end.
  • The original list is restored.
  • The algorithm runs in O(n) time.
  • The algorithm uses O(1) auxiliary space, excluding the cloned nodes themselves.
