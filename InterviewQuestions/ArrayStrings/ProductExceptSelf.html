Product of Array Except Self

1. Problem Statement

Return an array where each position contains the product of all elements except the element at that position. Division is not used.

Given an integer array nums, return an array answer such that:

answer[i] = product of every element in nums except nums[i]

The solution must not use the division operator.

Example

Input: [1, 2, 3, 4]

Output: [24, 12, 8, 6]

4. Main Idea

For every index i, the answer is:

answer[i] = product of elements to the LEFT of i × product of elements to the RIGHT of i

Therefore, we perform two passes:

  1. Calculate the product of all elements to the left.
  2. Calculate the product of all elements to the right.

5. First Pass - Prefix Products

During the first pass, store the product of all elements appearing before each index.

For [1, 2, 3, 4]:

Index 0 → left product = 1
Index 1 → left product = 1
Index 2 → left product = 1 × 2 = 2
Index 3 → left product = 1 × 2 × 3 = 6

6. Second Pass - Suffix Products

Starting from the right, multiply each answer value by the product of all elements appearing after that index.

For [1, 2, 3, 4]:

Index 3 → right product = 1
Index 2 → right product = 4
Index 1 → right product = 4 × 3 = 12
Index 0 → right product = 4 × 3 × 2 = 24

8. Pseudocode

FUNCTION productExceptSelf(nums) n = length(nums) create answer array of size n prefix = 1 FOR i = 0 TO n - 1 answer[i] = prefix prefix = prefix * nums[i] suffix = 1 FOR i = n - 1 DOWN TO 0 answer[i] = answer[i] * suffix suffix = suffix * nums[i] RETURN answer END FUNCTION

9. Python Implementation

def product_except_self(nums): n = len(nums) answer = [1] * n # Prefix products prefix = 1 for i in range(n): answer[i] = prefix prefix *= nums[i] # Suffix products suffix = 1 for i in range(n - 1, -1, -1): answer[i] *= suffix suffix *= nums[i] return answer # Example nums = [1, 2, 3, 4] print(product_except_self(nums))

Output:

[24, 12, 8, 6]

10. C++ Implementation

#include <iostream> #include <vector> using namespace std; vector<int> productExceptSelf(vector<int>& nums) { int n = nums.size(); vector<int> answer(n, 1); int prefix = 1; // Prefix products for (int i = 0; i < n; i++) { answer[i] = prefix; prefix *= nums[i]; } int suffix = 1; // Suffix products for (int i = n - 1; i >= 0; i--) { answer[i] *= suffix; suffix *= nums[i]; } return answer; } int main() { vector<int> nums = {1, 2, 3, 4}; vector<int> result = productExceptSelf(nums); for (int x : result) { cout << x << " "; } return 0; }

12. What Happens with Zero?

This method naturally handles zeros without any special division logic.

Input: [1, 2, 0, 4]

Output: [0, 0, 8, 0]

Notice that the answer at index 2 is:

1 × 2 × 4 = 8

13. Complexity Analysis

Time Complexity

O(n)

Two linear passes are performed.

Extra Space

O(1)

Apart from the output array, no additional array is required.

14. Important Points

  • Division is not used.
  • Works with positive numbers.
  • Works with negative numbers.
  • Works with zero.
  • Uses prefix and suffix products.
  • Time complexity is O(n).
  • Extra space is O(1), excluding the output array.
