Palindrome String Checker

1. Problem Statement

Given a string, determine whether it is a palindrome. Consider only alphanumeric characters (letters and digits) and ignore the difference between uppercase and lowercase letters.

Example:
Input: "A man, a plan, a canal: Panama"
Cleaned string: "amanaplanacanalpanama"
Output: True
Example:
Input: "race a car"
Cleaned string: "raceacar"
Output: False

3. Algorithm

  1. Convert the string to lowercase.
  2. Keep only alphanumeric characters.
  3. Initialize two pointers: left = 0 and right = length - 1.
  4. Compare the characters at the two pointers.
  5. If they are different, the string is not a palindrome.
  6. If they match, move both pointers toward the center.
  7. If all pairs match, the string is a palindrome.

4. Pseudocode

PALINDROME(s)

    cleaned = empty string

    for each character c in s
        if c is alphanumeric
            add lowercase(c) to cleaned

    left = 0
    right = length(cleaned) - 1

    while left < right

        if cleaned[left] != cleaned[right]
            return false

        left = left + 1
        right = right - 1

    return true

5. Python Implementation

def is_palindrome(s):
    cleaned = ""

    # Keep only alphanumeric characters
    for ch in s:
        if ch.isalnum():
            cleaned += ch.lower()

    left = 0
    right = len(cleaned) - 1

    while left < right:
        if cleaned[left] != cleaned[right]:
            return False

        left += 1
        right -= 1

    return True


# Example
s = "A man, a plan, a canal: Panama"

print(is_palindrome(s))
Output: True

6. Optimized Python Implementation

def is_palindrome(s):
    left = 0
    right = len(s) - 1

    while left < right:

        while left < right and not s[left].isalnum():
            left += 1

        while left < right and not s[right].isalnum():
            right -= 1

        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True

This version does not create a separate cleaned string. It directly skips non-alphanumeric characters using the two pointers.

7. Example Walkthrough

Input: "A man, a plan, a canal: Panama"

After removing spaces and punctuation:

amanaplanacanalpanama
  1. Compare a and a → Match
  2. Compare m and m → Match
  3. Compare a and a → Match
  4. Continue moving toward the center.
  5. Every pair matches.

Therefore, the string is a palindrome.

8. Complexity Analysis

Time Complexity

O(n)

Each character is examined at most once.

Space Complexity

O(n)

For the cleaned-string approach.

Optimized Space

O(1)

Using two pointers directly on the input.

9. Important Concepts

  • Palindrome: A string that reads the same forward and backward.
  • Alphanumeric: Letters A-Z, a-z and digits 0-9.
  • Case Insensitive: 'A' and 'a' are treated as equal.
  • Two Pointers: One pointer starts from the beginning and another from the end.
  • Early Termination: If any pair differs, we immediately return False.
