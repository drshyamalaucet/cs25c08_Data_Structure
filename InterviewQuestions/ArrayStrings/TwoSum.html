Two Sum II – Two Pointer Algorithm

Find two numbers in a 1-indexed, sorted array that add up to a target

```

1. Problem Statement

Given a 1-indexed, sorted array of integers numbers, find two numbers such that they add up to a specific target.

Return the indices of the two numbers as:

[index1, index2]

The array is sorted in non-decreasing order and the indices are 1-indexed, meaning the first element has index 1.

2. Example

Input:

numbers = [2, 7, 11, 15]
```

target = 9
```

Output:

[1, 2]

Because:

numbers[1] + numbers[2] = 2 + 7 = 9

4. Two Pointer Approach

Since the array is already sorted, we can use two pointers:

  • Left starts at the first element.
  • Right starts at the last element.
  • Calculate sum = numbers[left] + numbers[right].

If the sum is:

Condition Action Reason
sum == target Return the two indices Required pair is found
sum < target Move left forward Need a larger value
sum > target Move right backward Need a smaller value

5. Pseudocode

TwoSum(numbers, target)

left  ← 0
right ← length(numbers) - 1

while left < right

    sum ← numbers[left] + numbers[right]

    if sum = target
        return [left + 1, right + 1]

    else if sum < target
        left ← left + 1

    else
        right ← right - 1

return [-1, -1]

Note: We add 1 to the indices because the problem uses 1-based indexing.

6. Python Implementation

def two_sum(numbers, target):
left = 0
right = len(numbers) - 1

while left < right:
    current_sum = numbers[left] + numbers[right]

    if current_sum == target:
        return [left + 1, right + 1]

    elif current_sum < target:
        left += 1

    else:
        right -= 1

return [-1, -1]
```

# Example

numbers = [2, 7, 11, 15]
target = 9

result = two_sum(numbers, target)

print("Result:", result)
```

Output:

Result: [1, 2]

7. Step-by-Step Example

Step Left Right Values Sum Action
1 1 4 2 + 15 17 17 > 9 → Move Right
2 1 3 2 + 11 13 13 > 9 → Move Right
3 1 2 2 + 7 9 9 = 9 → Pair Found

8. Why Does the Two-Pointer Method Work?

The array is sorted. Therefore, when the current sum is too large, moving the right pointer to the left decreases the sum.

Similarly, when the current sum is too small, moving the left pointer to the right increases the sum.

This allows us to eliminate many possible pairs without checking every combination.

O(n²) brute force → O(n) two pointers

9. Complexity Analysis

Time Complexity

O(n)

Each pointer moves at most n positions.

Space Complexity

O(1)

Only two pointer variables are required.

Array Requirement

The array must be sorted.

10. Brute Force vs Two Pointer

Method Time Space Requirement
Brute Force O(n²) O(1) Works on unsorted arrays
Hash Table O(n) O(n) Does not require sorting
Two Pointers O(n) O(1) Array must be sorted
```
