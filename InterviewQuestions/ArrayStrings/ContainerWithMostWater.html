Container With Most Water

Visualizing the Two-Pointer Algorithm

1. Problem Statement

```

You are given an array height, where each element represents the height of a vertical line.

Find two lines that, together with the x-axis, form a container that holds the maximum amount of water.

Area = min(height[left], height[right]) × (right − left)

The two selected lines cannot be tilted. The container is determined by the shorter line and the distance between the two lines.

```

2. Example

``` 
height = [1,8,6,2,5,4,8,3,7]

The maximum container is formed using heights 8 and 7.

Area = min(8, 7) × (8 − 1) = 7 × 7 = 49

Maximum Water = 49

```

4. Two-Pointer Algorithm

```

Place one pointer at the beginning of the array and another pointer at the end.

  1. Set left = 0.
  2. Set right = n - 1.
  3. Calculate the current width.
  4. Find the shorter of the two lines.
  5. Calculate the current container area.
  6. Update the maximum area if necessary.
  7. Move the pointer at the shorter line.
  8. Continue until left and right meet.
Current Area = min(height[left], height[right]) × (right - left)
```

5. Pseudocode

MaxArea(height)

    left  ← 0
    right ← length(height) - 1
    maxArea ← 0

    while left < right

        width ← right - left

        currentHeight ←
            min(height[left], height[right])

        currentArea ←
            currentHeight × width

        maxArea ←
            max(maxArea, currentArea)

        if height[left] < height[right]
            left ← left + 1
        else
            right ← right - 1

    return maxArea

6. Python Implementation

def max_area(height):
    left = 0
    right = len(height) - 1

    max_water = 0

    while left < right:

        width = right - left

        current_height = min(
            height[left],
            height[right]
        )

        current_area = current_height * width

        max_water = max(
            max_water,
            current_area
        )

        if height[left] < height[right]:
            left += 1
        else:
            right -= 1

    return max_water


# Example
height = [1,8,6,2,5,4,8,3,7]

result = max_area(height)

print("Maximum water:", result)

8. Why Move the Shorter Line?

```

The amount of water is limited by the shorter line:

Area = shorter height × width

Suppose the left line is shorter than the right line. Moving the right pointer cannot increase the height limit because the left line is still the limiting line.

Therefore, we move the left pointer in an attempt to find a taller line.

The same logic applies when the right line is shorter.

```

9. Complexity Analysis

```

Time Complexity

O(n)

Each pointer moves toward the other only once.

Space Complexity

O(1)

Only a few variables are used.

Brute Force

O(n²)

Every pair of lines is checked.

```

10. Brute Force vs Two Pointers

```
Approach Time Space
Brute Force O(n²) O(1)
```
