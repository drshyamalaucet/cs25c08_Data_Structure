3Sum – Unique Triplets

Find all unique triplets that sum to zero

1. Problem Statement

Given an unsorted integer array, find all unique triplets [a, b, c] such that:

a + b + c = 0

Duplicate triplets must not be included in the result. 

Input:
[-1, 0, 1, 2, -1, -4]

Output:
[[-1, -1, 2], [-1, 0, 1]]

3. Algorithm

  1. Sort the input array.
  2. Select one element as the fixed element.
  3. Set Left pointer to the next element.
  4. Set Right pointer to the last element.
  5. Calculate the sum of the three values.
  6. If sum is zero, save the triplet.
  7. If sum is less than zero, move Left forward.
  8. If sum is greater than zero, move Right backward.
  9. Skip duplicate values.

4. Pseudocode

ThreeSum(nums)

    sort(nums)

    result = []

    for i = 0 to n - 3

        if i > 0 and nums[i] == nums[i - 1]
            continue

        left = i + 1
        right = n - 1

        while left < right

            sum = nums[i] + nums[left] + nums[right]

            if sum == 0

                add [nums[i], nums[left], nums[right]]

                skip duplicate left values
                skip duplicate right values

                left++
                right--

            else if sum < 0

                left++

            else

                right--

    return result

5. Python Implementation

def three_sum(nums):

    nums.sort()

    result = []

    for i in range(len(nums) - 2):

        # Skip duplicate fixed values
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        left = i + 1
        right = len(nums) - 1

        while left < right:

            total = nums[i] + nums[left] + nums[right]

            if total == 0:

                result.append([
                    nums[i],
                    nums[left],
                    nums[right]
                ])

                # Skip duplicates
                while left < right and \
                      nums[left] == nums[left + 1]:
                    left += 1

                while left < right and \
                      nums[right] == nums[right - 1]:
                    right -= 1

                left += 1
                right -= 1

            elif total < 0:

                left += 1

            else:

                right -= 1

    return result


# Example

nums = [-1, 0, 1, 2, -1, -4]

print(three_sum(nums))

Output: 

[[-1, -1, 2], [-1, 0, 1]]

6. Why Two Pointers?

After sorting the array, we can efficiently find the other two elements using two pointers.

nums[i] + nums[left] + nums[right] = 0

If the sum is too small, increase Left.

If the sum is too large, decrease Right.

This avoids checking every possible combination using three nested loops.

O(n log n)

O(n²)

O(n²)

O(1)
