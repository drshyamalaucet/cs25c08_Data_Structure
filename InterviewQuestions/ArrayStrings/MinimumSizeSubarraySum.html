Minimum Size Subarray Sum

1. Problem Statement

Given an array of positive integers and a target value, find the minimum length of a contiguous subarray whose sum is greater than or equal to the target.

If no such subarray exists, return 0.

Example:
Target = 7
Array = [2, 3, 1, 2, 4, 3]

The subarray [4, 3] has sum 7.
Minimum length = 2

3. Sliding Window Algorithm

  1. Initialize left = 0, current_sum = 0, and minimum_length = ∞.
  2. Move the right pointer through the array.
  3. Add each element to current_sum.
  4. When current_sum ≥ target, the current window is valid.
  5. Record its length if it is smaller than the current minimum.
  6. Move the left pointer forward to make the window smaller.
  7. Continue until the right pointer reaches the end.
  8. If no valid subarray was found, return 0.

4. Pseudocode

MIN_SUBARRAY_LENGTH(target, nums)

    left = 0
    currentSum = 0
    minLength = infinity

    for right = 0 to length(nums) - 1

        currentSum = currentSum + nums[right]

        while currentSum >= target

            currentLength = right - left + 1

            minLength =
                minimum(minLength, currentLength)

            currentSum =
                currentSum - nums[left]

            left = left + 1

    if minLength == infinity
        return 0
    else
        return minLength

5. Python Implementation

def min_subarray_length(target, nums):

    left = 0
    current_sum = 0
    min_length = float('inf')

    for right in range(len(nums)):

        current_sum += nums[right]

        while current_sum >= target:

            current_length = right - left + 1

            min_length = min(
                min_length,
                current_length
            )

            current_sum -= nums[left]

            left += 1

    if min_length == float('inf'):
        return 0

    return min_length


# Example
target = 7
nums = [2, 3, 1, 2, 4, 3]

answer = min_subarray_length(target, nums)

print("Minimum length:", answer)
Output: Minimum length: 2

7. Complexity Analysis

Time Complexity

O(n)

Each element enters and leaves the sliding window at most once.

Space Complexity

O(1)

Only a few variables are required.

8. Important Concepts

  • Contiguous Subarray: Elements must appear consecutively in the original array.
  • Positive Integers: The sliding-window technique works because increasing the window increases the sum and removing elements decreases it.
  • Sliding Window: The range between the left and right pointers.
  • Expand: Move the right pointer to increase the window and sum.
  • Shrink: Move the left pointer to find a shorter valid window.
  • Minimum: Keep updating the answer whenever a shorter valid window is found.
