Longest Substring Without Duplicate Characters

1. Problem Statement

Given a string, find the length of the longest substring that contains no duplicate characters.

Example 1:
Input: "abcabcbb"
Longest substring: "abc"
Length: 3
Example 2:
Input: "bbbbb"
Longest substring: "b"
Length: 1
Example 3:
Input: "pwwkew"
Longest substring: "wke"
Length: 3

3. Sliding Window Algorithm

  1. Create a window using two pointers: left and right.
  2. Move the right pointer through the string.
  3. Store characters currently inside the window.
  4. If a duplicate character is found, move the left pointer.
  5. Continue until the duplicate is removed.
  6. Calculate the current window length.
  7. Update the maximum length.

This technique is called the Sliding Window Algorithm.

4. Pseudocode

LONGEST_SUBSTRING(s)

    left = 0
    maxLength = 0
    characters = empty set

    for right = 0 to length(s) - 1

        while s[right] is already in characters

            remove s[left] from characters
            left = left + 1

        add s[right] to characters

        currentLength = right - left + 1

        maxLength =
            maximum(maxLength, currentLength)

    return maxLength

5. Python Implementation

def length_of_longest_substring(s):

    characters = set()

    left = 0
    max_length = 0

    for right in range(len(s)):

        while s[right] in characters:
            characters.remove(s[left])
            left += 1

        characters.add(s[right])

        current_length = right - left + 1

        max_length = max(
            max_length,
            current_length
        )

    return max_length


# Example
s = "abcabcbb"

result = length_of_longest_substring(s)

print("Longest length:", result)
Output: Longest length: 3

6. Optimized Python Implementation

def length_of_longest_substring(s):

    last_seen = {}

    left = 0
    max_length = 0

    for right, ch in enumerate(s):

        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1

        last_seen[ch] = right

        max_length = max(
            max_length,
            right - left + 1
        )

    return max_length


s = "abcabcbb"

print(length_of_longest_substring(s))

The dictionary stores the last position at which each character was found. Therefore, the left pointer can jump directly to the required position.

8. Complexity Analysis

Time Complexity

O(n)

Each character is processed efficiently.

Space Complexity

O(k)

k = number of distinct characters.

9. Important Concepts

  • Substring: A contiguous portion of a string.
  • Duplicate Character: A character that appears more than once in the current window.
  • Sliding Window: A dynamic range represented by left and right pointers.
  • Set: Used to keep track of characters currently in the window.
  • Two Pointers: The left pointer removes duplicates while the right pointer expands the window.
