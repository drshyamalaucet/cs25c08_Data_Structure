Subarray Sum Equals K

Find the total number of continuous subarrays whose sum is equal to a given target k.

1. Problem Statement

Given an array of integers and an integer k, find the total number of continuous subarrays whose sum is exactly equal to k.

Example:

Array = [1, 2, 3]
k = 3

Valid subarrays:
[1, 2] → 3
[3] → 3

Answer = 2

5. Pseudocode

FUNCTION subarraySum(nums, k) prefixSum = 0 count = 0 create hashmap hashmap[0] = 1 FOR each number x in nums prefixSum = prefixSum + x required = prefixSum - k IF required exists in hashmap count = count + hashmap[required] hashmap[prefixSum] = hashmap[prefixSum] + 1 RETURN count END FUNCTION

6. Algorithm Explanation

The efficient solution uses the concept of a Prefix Sum.

Prefix Sum = Sum of all elements from the beginning of the array up to the current position.

Suppose the current prefix sum is P. We want a subarray whose sum is k.

Therefore:
Previous Prefix Sum + k = Current Prefix Sum

Previous Prefix Sum = Current Prefix Sum - k

Therefore, we search the hash map for:
P - k

If P - k has occurred before, every occurrence gives us one continuous subarray whose sum is exactly k.

7. Step-by-Step Example

Final Answer = 2

8. Python Implementation

def subarray_sum(nums, k): prefix_sum = 0 count = 0 # prefix_sum : frequency prefix_count = {0: 1} for num in nums: prefix_sum += num required = prefix_sum - k if required in prefix_count: count += prefix_count[required] prefix_count[prefix_sum] = \ prefix_count.get(prefix_sum, 0) + 1 return count # Example nums = [1, 2, 3] k = 3 print(subarray_sum(nums, k))

Output:

2

9. Brute Force Approach

A simple solution is to consider every possible starting position and calculate the sum of every subarray.

def subarray_sum_brute_force(nums, k): count = 0 for i in range(len(nums)): current_sum = 0 for j in range(i, len(nums)): current_sum += nums[j] if current_sum == k: count += 1 return count

Although this approach is easy to understand, it takes O(n²) time.

10. Complexity Analysis

Time Complexity

O(n)

Each array element is processed once.

Space Complexity

O(n)

The hash map can contain up to n different prefix sums.

11. Important Points

  • The array does not need to be sorted.
  • Negative numbers are allowed.
  • Zero values are allowed.
  • The subarray must be continuous.
  • The target can be positive, negative, or zero.
  • Prefix Sum + Hash Map gives an O(n) solution.
