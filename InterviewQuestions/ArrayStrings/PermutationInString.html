Permutation in String

Sliding Window Algorithm – Interactive Visualizer

1. Problem Statement

Given two strings s1 and s2, return true if s2 contains a permutation of s1. Otherwise, return false.
Example:

s1 = "ab"
s2 = "eidbaooo"

The substring "ba" is a permutation of "ab".

Therefore: true

A permutation contains the same characters with the same frequencies, but the characters can appear in a different order.

3. Algorithm Idea

If s1 has length m, every permutation of s1 must also have exactly m characters.

Therefore, we create a sliding window of size m inside s2.

  1. Count the frequency of characters in s1.
  2. Create a window of the same size in s2.
  3. Compare the frequency counts.
  4. If the frequencies are equal, return true.
  5. Otherwise, move the window one position to the right.
  6. Add the new character and remove the character that leaves the window.
Window Size = length(s1)

Compare:
Frequency(s1) == Frequency(Current Window)

4. Pseudocode

Algorithm CheckPermutation(s1, s2)

1. If length(s1) > length(s2)
       return false

2. Count the frequency of every character in s1

3. Create a window of length s1 in s2

4. Count the frequency of characters in the window

5. If both frequency arrays are equal
       return true

6. Move the window one position to the right

7. Add the new character to the window

8. Remove the old character from the window

9. Compare the frequencies again

10. Repeat until all windows are checked

11. Return false

5. Python Implementation

from collections import Counter

def checkInclusion(s1, s2):

    m = len(s1)

    # s1 cannot fit inside s2
    if m > len(s2):
        return False

    # Frequency of characters in s1
    need = Counter(s1)

    # Frequency of first window
    window = Counter(s2[:m])

    # Check first window
    if need == window:
        return True

    # Sliding window
    for right in range(m, len(s2)):

        # Add new character
        window[s2[right]] += 1

        # Remove character leaving window
        left_char = s2[right - m]

        window[left_char] -= 1

        if window[left_char] == 0:
            del window[left_char]

        # Compare frequencies
        if need == window:
            return True

    return False


s1 = "ab"
s2 = "eidbaooo"

result = checkInclusion(s1, s2)

6. Optimized Python Implementation

def checkInclusion(s1, s2):

    if len(s1) > len(s2):
        return False

    count1 = [0] * 26
    count2 = [0] * 26

    # Count characters in s1
    for ch in s1:
        count1[ord(ch) - ord('a')] += 1

    # First window
    for i in range(len(s1)):
        count2[ord(s2[i]) - ord('a')] += 1

    # Compare first window
    if count1 == count2:
        return True

    # Sliding window
    for right in range(len(s1), len(s2)):

        # Add new character
        count2[ord(s2[right]) - ord('a')] += 1

        # Remove old character
        left = right - len(s1)

        count2[ord(s2[left]) - ord('a')] -= 1

        if count1 == count2:
            return True

    return False


print(checkInclusion("ab", "eidbaooo"))

9. Why Sliding Window?

A simple approach would generate every permutation of s1 and search for each permutation in s2.

This is inefficient because the number of permutations can be very large.

Instead of generating permutations,

Check character frequencies in fixed-size windows.

The order of characters does not matter. Only their frequency matters.

10. Complexity Analysis

Time Complexity

O(n)

Each character enters and leaves the sliding window at most once.

Space Complexity

O(1)

Only 26 character frequency counters are needed for lowercase English letters.

12. Final Summary

Technique: Sliding Window

Window Size: length(s1)

Main Data Structure: Frequency Counter

Condition: Frequency(s1) == Frequency(window)

Time Complexity: O(n)

Space Complexity: O(1)

If any window in s2 has exactly the same character frequencies as s1, then s2 contains a permutation of s1.
