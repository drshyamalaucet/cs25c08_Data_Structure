Maximum Points You Can Obtain from Cards

1. Problem Statement

Several cards are arranged in a row. Each card contains a number of points.

In one step, you can take exactly one card from either:

  • The beginning of the row
  • The end of the row

Given an integer k, find the maximum number of points you can obtain by taking exactly k cards.

Example:

Cards: [1, 2, 3, 4, 5, 6, 1]
k = 3

One optimal choice is: 1 + 6 + 5 = 12

Maximum points = 12

3. Key Idea – Sliding Window

Suppose the array contains n cards and we must take exactly k cards.

Instead of trying every combination of cards taken from the left and right, observe that:

Taking k cards from the two ends is equivalent to leaving n - k consecutive cards in the middle.

Therefore:

  1. Calculate the total points of all cards.
  2. Find the minimum sum of any window of length n - k.
  3. Subtract that minimum middle sum from the total sum.
Maximum Points
=
Total Points
-
Minimum Sum of (n - k) Consecutive Cards

4. Algorithm

  1. Calculate the total sum of all card points.
  2. Let windowSize = n - k.
  3. Find the minimum sum of a contiguous window of size windowSize.
  4. The cards outside this minimum window are the cards taken.
  5. Return: Total Sum - Minimum Window Sum.

This reduces the problem from potentially exponential choices to an efficient O(n) sliding-window solution.

5. Pseudocode

MAX_POINTS(cards, k)

    n = length(cards)

    total = sum(cards)

    windowSize = n - k

    if windowSize == 0
        return total

    windowSum = sum of first windowSize cards

    minWindowSum = windowSum

    for i = windowSize to n - 1

        windowSum =
            windowSum
            + cards[i]
            - cards[i - windowSize]

        minWindowSum =
            minimum(
                minWindowSum,
                windowSum
            )

    return total - minWindowSum

6. Python Implementation

def max_score(cards, k):

    n = len(cards)

    total = sum(cards)

    window_size = n - k

    if window_size == 0:
        return total

    window_sum = sum(cards[:window_size])

    min_window_sum = window_sum

    for i in range(window_size, n):

        window_sum += cards[i]
        window_sum -= cards[i - window_size]

        min_window_sum = min(
            min_window_sum,
            window_sum
        )

    return total - min_window_sum


# Example
cards = [1, 2, 3, 4, 5, 6, 1]
k = 3

print("Maximum points:",
      max_score(cards, k))
Output: Maximum points: 12

7. Alternative Two-Sided Approach

We can also directly consider all possible combinations of taking some cards from the left and the remaining cards from the right. 

def max_score(cards, k):

    current = sum(cards[:k])
    answer = current

    n = len(cards)

    for i in range(k):

        current -= cards[k - 1 - i]

        current += cards[n - 1 - i]

        answer = max(answer, current)

    return answer


cards = [1, 2, 3, 4, 5, 6, 1]
k = 3

print(max_score(cards, k))

For teaching purposes, this version is particularly intuitive: start by taking all k cards from the left, then gradually replace left cards with cards from the right.

9. Complexity Analysis

Time Complexity

O(n)

Each card is processed a constant number of times.

Space Complexity

O(1)

Only a few variables are used.

10. Important Concepts

  • Exactly k: The algorithm must select exactly k cards.
  • Two Ends: A card can only be selected from the beginning or the end.
  • Sliding Window: Instead of maximizing the selected cards directly, minimize the cards that remain.
  • Complementary Approach: Taking k cards means leaving n-k cards.
  • Minimum Window: The minimum-sum window represents the cards that should be left.
