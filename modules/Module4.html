1. Linear and Binary Search

Linear Search

Linear search examines elements one by one until the required element is found.

Example:
Array = [12, 25, 8, 40, 17]
Search = 40
The algorithm checks 12 → 25 → 8 → 40.

Pseudocode

LinearSearch(A, n, key)

for i = 0 to n-1
if A[i] == key
return i
return -1

C++

int linearSearch(vector<int> A, int key) {
    for (int i = 0; i < A.size(); i++) {
        if (A[i] == key)
            return i;
    }
    return -1;
}

Time: O(n)

Binary Search

Binary search repeatedly divides a sorted array into two halves.

Important: Binary search requires the array to be sorted.

Pseudocode

BinarySearch(A, n, key)

low = 0
high = n - 1

while low <= high
mid = (low + high) / 2

```
if A[mid] == key
    return mid

else if key < A[mid]
    high = mid - 1

else
    low = mid + 1
```

return -1

C++

int binarySearch(vector<int> A, int key) {

```
int low = 0;
int high = A.size() - 1;

while (low <= high) {

    int mid = low + (high - low) / 2;

    if (A[mid] == key)
        return mid;

    if (key < A[mid])
        high = mid - 1;
    else
        low = mid + 1;
}

return -1;
```

}

Time: O(log n)

2. Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. After every pass, the largest unsorted element moves to the end.

Idea: Compare → Swap → Repeat.

Pseudocode

BubbleSort(A, n)

for i = 0 to n-2

    for j = 0 to n-i-2

        if A[j] > A[j+1]

            swap(A[j], A[j+1])

C++ Implementation

void bubbleSort(vector<int>& A) {

    int n = A.size();

    for (int i = 0; i < n - 1; i++) {

        bool swapped = false;

        for (int j = 0; j < n - i - 1; j++) {

            if (A[j] > A[j + 1]) {

                swap(A[j], A[j + 1]);
                swapped = true;
            }
        }

        if (!swapped)
            break;
    }
}

Best: O(n)   Average: O(n²)   Worst: O(n²)

3. Insertion Sort

Insertion Sort builds the sorted array one element at a time. Each new element is inserted into its correct position.

Pseudocode

InsertionSort(A, n)

for i = 1 to n-1

    key = A[i]
    j = i - 1

    while j >= 0 and A[j] > key

        A[j+1] = A[j]
        j = j - 1

    A[j+1] = key

C++ Implementation

void insertionSort(vector<int>& A) {

    for (int i = 1; i < A.size(); i++) {

        int key = A[i];
        int j = i - 1;

        while (j >= 0 && A[j] > key) {

            A[j + 1] = A[j];
            j--;
        }

        A[j + 1] = key;
    }
}
Best
O(n)
Average
O(n²)
Worst
O(n²)
Space
O(1)

4. Merge Sort

Merge Sort follows the divide-and-conquer strategy. The array is divided into smaller arrays, sorted recursively, and then merged.

Process

1. Divide
Split the array into two halves.
2. Conquer
Sort each half recursively.
3. Merge
Combine sorted halves.

Pseudocode

MergeSort(A, left, right)

if left < right

    mid = (left + right) / 2

    MergeSort(A, left, mid)
    MergeSort(A, mid + 1, right)

    Merge(A, left, mid, right)

C++ Implementation

void merge(vector<int>& A, int l, int m, int r) {

    vector<int> temp;

    int i = l;
    int j = m + 1;

    while (i <= m && j <= r) {

        if (A[i] <= A[j])
            temp.push_back(A[i++]);
        else
            temp.push_back(A[j++]);
    }

    while (i <= m)
        temp.push_back(A[i++]);

    while (j <= r)
        temp.push_back(A[j++]);

    for (int k = 0; k < temp.size(); k++)
        A[l + k] = temp[k];
}

void mergeSort(vector<int>& A, int l, int r) {

    if (l < r) {

        int m = l + (r - l) / 2;

        mergeSort(A, l, m);
        mergeSort(A, m + 1, r);

        merge(A, l, m, r);
    }
}

Time: O(n log n)

Space: O(n)

5. Bucket Sort

Bucket Sort distributes elements into several buckets. Each bucket is sorted separately and the buckets are concatenated.

Bucket Sort works particularly well when values are uniformly distributed over a known range.

Bucket Visualization

```
Bucket 0
Empty
Bucket 1
Empty
Bucket 2
Empty
Bucket 3
Empty
Bucket 4
Empty
```

Pseudocode

BucketSort(A)

create k empty buckets

for each element x in A

    index = bucketIndex(x)
    insert x into bucket[index]

for each bucket

    sort(bucket)

concatenate all buckets

C++ Implementation

void bucketSort(vector<float>& A) {

    int n = A.size();

    vector<vector<float>> buckets(n);

    for (float x : A) {

        int index = n * x;

        if (index == n)
            index = n - 1;

        buckets[index].push_back(x);
    }

    for (auto& bucket : buckets)
        sort(bucket.begin(), bucket.end());

    int k = 0;

    for (auto& bucket : buckets)
        for (float x : bucket)
            A[k++] = x;
}

Average Time: O(n + k)

6. Quick Sort

Quick Sort selects a pivot, partitions the array around the pivot, and recursively sorts the two partitions.

Example: Choose 45 as pivot. Values smaller than 45 go left and values larger than 45 go right.

Pseudocode

QuickSort(A, low, high)

if low < high

    p = Partition(A, low, high)

    QuickSort(A, low, p - 1)

    QuickSort(A, p + 1, high)

C++ Implementation

int partition(vector<int>& A, int low, int high) {

    int pivot = A[high];

    int i = low - 1;

    for (int j = low; j < high; j++) {

        if (A[j] < pivot) {

            i++;
            swap(A[i], A[j]);
        }
    }

    swap(A[i + 1], A[high]);

    return i + 1;
}

void quickSort(vector<int>& A, int low, int high) {

    if (low < high) {

        int p = partition(A, low, high);

        quickSort(A, low, p - 1);
        quickSort(A, p + 1, high);
    }
}
Best
O(n log n)
Average
O(n log n)
Worst
O(n²)
Space
O(log n)

7. Heap Sort

Heap Sort uses a binary heap. For ascending order, a Max Heap is constructed and the largest element is repeatedly moved to the end.

Heap Representation

              50
            /    \
          30      40
         /  \    /  \
       10   20  15   25

Max Heap:
Parent >= Children

Pseudocode

HeapSort(A)

BuildMaxHeap(A)

for i = n-1 down to 1

    swap(A[0], A[i])

    Heapify(A, 0, i)

C++ Implementation

void heapify(vector<int>& A, int n, int i) {

    int largest = i;

    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < n && A[left] > A[largest])
        largest = left;

    if (right < n && A[right] > A[largest])
        largest = right;

    if (largest != i) {

        swap(A[i], A[largest]);

        heapify(A, n, largest);
    }
}

void heapSort(vector<int>& A) {

    int n = A.size();

    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(A, n, i);

    for (int i = n - 1; i > 0; i--) {

        swap(A[0], A[i]);

        heapify(A, i, 0);
    }
}

Time: O(n log n)

Space: O(1)

8. Hashing Table ADT

A hash table stores key-value data using a hash function to calculate the location of a key.

Hash Function: h(key) = key % tableSize

Example

Key Table Size Hash Value
25 10 5
37 10 7
42 10 2

8.1 Separate Chaining

In separate chaining, every hash-table position contains a list of elements. Multiple keys can therefore occupy the same index.

```
Index
Hash
Chain
0
k % 7
—
1
k % 7
15 → 22 → 29
2
k % 7
9 → 16
3
k % 7
10
```

Pseudocode

Insert(key)

index = hash(key)

chain[index].push_back(key)


Search(key)

index = hash(key)

search key in chain[index]

C++ Implementation

class HashTable {

    int size;

    vector<list<int>> table;

public:

    HashTable(int s) {

        size = s;
        table.resize(size);
    }

    int hashFunction(int key) {

        return key % size;
    }

    void insert(int key) {

        int index = hashFunction(key);

        table[index].push_back(key);
    }

    bool search(int key) {

        int index = hashFunction(key);

        for (int x : table[index]) {

            if (x == key)
                return true;
        }

        return false;
    }

    void display() {

        for (int i = 0; i < size; i++) {

            cout << i << ": ";

            for (int x : table[i])
                cout << x << " -> ";

            cout << "NULL\n";
        }
    }
};

8.2 Open Addressing

In open addressing, all elements are stored directly inside the hash table. When a collision occurs, another empty location is searched.

Linear Probing

A simple open-addressing technique is linear probing.

Index 0 1 2 3 4 5 6
Key — 22 15 29 — 12 —

If 22 % 7 = 1, place 22 at index 1. If another key hashes to index 1, check index 2, then 3, etc.

Pseudocode

Insert(key)

index = hash(key)

while table[index] is occupied

    index = (index + 1) % tableSize

table[index] = key


Search(key)

index = hash(key)

while table[index] is not empty

    if table[index] == key
        return true

    index = (index + 1) % tableSize

return false

C++ Implementation

class LinearProbingHash {

    int size;
    vector<int> table;
    const int EMPTY = -1;

public:

    LinearProbingHash(int s) {

        size = s;
        table.assign(size, EMPTY);
    }

    int hashFunction(int key) {

        return key % size;
    }

    bool insert(int key) {

        int index = hashFunction(key);

        for (int i = 0; i < size; i++) {

            int pos = (index + i) % size;

            if (table[pos] == EMPTY) {

                table[pos] = key;
                return true;
            }
        }

        return false;
    }

    bool search(int key) {

        int index = hashFunction(key);

        for (int i = 0; i < size; i++) {

            int pos = (index + i) % size;

            if (table[pos] == EMPTY)
                return false;

            if (table[pos] == key)
                return true;
        }

        return false;
    }

    void display() {

        for (int i = 0; i < size; i++)
            cout << i << " : " << table[i] << endl;
    }
};

10. Important Exam Points

Searching

  • Linear search works on sorted or unsorted data.
  • Binary search requires sorted data.
  • Binary search is faster for large sorted arrays.

Sorting

  • Bubble Sort uses adjacent swaps.
  • Insertion Sort grows a sorted prefix.
  • Merge Sort uses divide and conquer.
  • Quick Sort uses partitioning.
  • Heap Sort uses a binary heap.
  • Bucket Sort distributes data into buckets.

Hashing

  • Hash function maps keys to indexes.
  • Collision occurs when two keys get the same index.
  • Chaining stores collided values in lists.
  • Open addressing searches another table location.
  • Linear probing checks consecutive locations.
