1. What is an AVL Tree?

An AVL Tree is a self-balancing Binary Search Tree. After every insertion or deletion, the tree checks its balance factor and performs rotations when necessary.

Balance Factor:
BF(node) = Height(Left Subtree) − Height(Right Subtree)

For an AVL tree: -1 ≤ BF ≤ +1
Case Condition Rotation
LL BF > 1 and key < left.key Right Rotation
RR BF < -1 and key > right.key Left Rotation
LR BF > 1 and key > left.key Left Rotation + Right Rotation
RL BF < -1 and key < right.key Right Rotation + Left Rotation

3. AVL Rotation Types

LL Case – Right Rotation

The new node is inserted into the left subtree of the left child.

Before: 30 / 20 / 10 After Right Rotation: 20 / \ 10 30

Solution: Perform one right rotation around node 30.

RR Case – Left Rotation

The new node is inserted into the right subtree of the right child.

Before: 10 \ 20 \ 30 After Left Rotation: 20 / \ 10 30

Solution: Perform one left rotation around node 10.

LR Case – Left then Right

The new node is inserted into the right subtree of the left child.

Before: 30 / 10 \ 20 Step 1: Left Rotation 30 / 20 / 10 Step 2: Right Rotation 20 / \ 10 30

RL Case – Right then Left

The new node is inserted into the left subtree of the right child.

Before: 10 \ 30 / 20 Step 1: Right Rotation 10 \ 20 \ 30 Step 2: Left Rotation 20 / \ 10 30

4. AVL Rotation Pseudocode

Right Rotation

RIGHT-ROTATE(y)

    x = y.left
    T2 = x.right

    x.right = y
    y.left = T2

    update height of y
    update height of x

    return x

Left Rotation

LEFT-ROTATE(x)

    y = x.right
    T2 = y.left

    y.left = x
    x.right = T2

    update height of x
    update height of y

    return y

AVL Insertion

INSERT(node, key)

    if node is NULL
        create new node
        return node

    if key < node.key
        node.left = INSERT(node.left, key)

    else if key > node.key
        node.right = INSERT(node.right, key)

    else
        return node

    update node.height

    balance = height(left) - height(right)

    if balance > 1 and key < node.left.key
        return RIGHT-ROTATE(node)

    if balance < -1 and key > node.right.key
        return LEFT-ROTATE(node)

    if balance > 1 and key > node.left.key
        node.left = LEFT-ROTATE(node.left)
        return RIGHT-ROTATE(node)

    if balance < -1 and key < node.right.key
        node.right = RIGHT-ROTATE(node.right)
        return LEFT-ROTATE(node)

    return node

5. C++ Implementation

#include <iostream>
#include <algorithm>
using namespace std;

struct Node {
    int key;
    Node* left;
    Node* right;
    int height;

    Node(int value) {
        key = value;
        left = nullptr;
        right = nullptr;
        height = 1;
    }
};

int height(Node* node) {
    if (node == nullptr)
        return 0;

    return node->height;
}

int getBalance(Node* node) {
    if (node == nullptr)
        return 0;

    return height(node->left) -
           height(node->right);
}

/* RIGHT ROTATION
 *
 *        y                  x
 *       / \                / \
 *      x   T3     ->       T1  y
 *     / \                    / \
 *    T1 T2                  T2 T3
 */

Node* rightRotate(Node* y) {

    Node* x = y->left;
    Node* T2 = x->right;

    // Rotation
    x->right = y;
    y->left = T2;

    // Update heights
    y->height =
        1 + max(height(y->left),
                height(y->right));

    x->height =
        1 + max(height(x->left),
                height(x->right));

    return x;
}

/* LEFT ROTATION
 *
 *      x                      y
 *     / \                    / \
 *    T1  y       ->         x  T3
 *       / \                / \
 *      T2 T3              T1 T2
 */

Node* leftRotate(Node* x) {

    Node* y = x->right;
    Node* T2 = y->left;

    // Rotation
    y->left = x;
    x->right = T2;

    // Update heights
    x->height =
        1 + max(height(x->left),
                height(x->right));

    y->height =
        1 + max(height(y->left),
                height(y->right));

    return y;
}

Node* insert(Node* node, int key) {

    // Normal BST insertion
    if (node == nullptr)
        return new Node(key);

    if (key < node->key)
        node->left =
            insert(node->left, key);

    else if (key > node->key)
        node->right =
            insert(node->right, key);

    else
        return node;

    // Update height
    node->height =
        1 + max(height(node->left),
                height(node->right));

    // Calculate balance factor
    int balance = getBalance(node);

    // LL Case
    if (balance > 1 &&
        key < node->left->key)

        return rightRotate(node);

    // RR Case
    if (balance < -1 &&
        key > node->right->key)

        return leftRotate(node);

    // LR Case
    if (balance > 1 &&
        key > node->left->key) {

        node->left =
            leftRotate(node->left);

        return rightRotate(node);
    }

    // RL Case
    if (balance < -1 &&
        key < node->right->key) {

        node->right =
            rightRotate(node->right);

        return leftRotate(node);
    }

    return node;
}

void inorder(Node* root) {

    if (root == nullptr)
        return;

    inorder(root->left);
    cout << root->key << " ";
    inorder(root->right);
}

int main() {

    Node* root = nullptr;

    int values[] = {
        30, 20, 10,
        40, 50,
        25
    };

    for (int value : values)
        root = insert(root, value);

    cout << "Inorder Traversal: ";

    inorder(root);

    return 0;
}

6. Step-by-Step Explanation

Step 1 – Insert like a BST

AVL insertion initially follows the normal Binary Search Tree insertion procedure.

Step 2 – Update Height

After insertion, the height of every node on the path back to the root is updated.

Height = 1 + max(left height, right height)

Step 3 – Calculate Balance Factor

The balance factor is calculated as:

BF = Height(Left Subtree) − Height(Right Subtree)

Step 4 – Detect Imbalance

If the balance factor becomes greater than +1 or less than -1, the node is unbalanced.

Step 5 – Select Rotation

Imbalance Example Operation
LL 30 → 20 → 10 Right Rotation
RR 10 → 20 → 30 Left Rotation
LR 30 → 10 → 20 Left Rotation + Right Rotation
RL 10 → 30 → 20 Right Rotation + Left Rotation
