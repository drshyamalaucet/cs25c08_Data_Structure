🚀 Dijkstra's Shortest Path Algorithm

Interactive visualization + C++ implementation

1. What is Dijkstra's Algorithm?

```

Dijkstra's algorithm is a shortest path algorithm used to find the minimum-cost path from a source vertex to all other vertices in a weighted graph.

It repeatedly selects the unvisited vertex having the smallest tentative distance and relaxes all of its neighboring edges.

If dist[u] + weight(u,v) < dist[v], then dist[v] = dist[u] + weight(u,v)

Input

A weighted graph with non-negative edge weights.

Output

Shortest distance from the source to every reachable vertex.

Greedy Method

Always chooses the currently closest unvisited vertex.

Important

Dijkstra's algorithm does not work correctly with negative edge weights.
```

```
3. How Dijkstra's Algorithm Works

  1. Set the source vertex distance to 0.
  2. Set all other vertex distances to ∞.
  3. Select the unvisited vertex with the smallest distance.
  4. Mark that vertex as visited.
  5. Examine all neighboring vertices.
  6. Relax each edge.
  7. Update the distance if a shorter path is found.
  8. Repeat until all vertices are processed.
  9. Use the predecessor array to reconstruct the shortest path.
```

```
5. Pseudocode

``` 
DIJKSTRA(Graph, source)

for every vertex v:
    distance[v] = INFINITY
    previous[v] = NULL
    visited[v] = false

distance[source] = 0

repeat:

    u = unvisited vertex with minimum distance

    if u does not exist:
        break

    visited[u] = true

    for each neighbor v of u:

        newDistance =
            distance[u] + weight(u, v)

        if newDistance < distance[v]:

            distance[v] = newDistance
            previous[v] = u

return distance[] and previous[]
```

6. C++ Implementation

``` 
#include <iostream>
#include <vector>
#include <queue>
#include <climits>
#include <algorithm>

using namespace std;

typedef pair<int, int> PII;

void dijkstra(
    int V,
    vector<vector<PII>>& graph,
    int source
) {
    vector<int> dist(V, INT_MAX);
    vector<int> parent(V, -1);

    priority_queue<
        PII,
        vector<PII>,
        greater<PII>
    > pq;

    dist[source] = 0;

    pq.push({0, source});

    while (!pq.empty()) {

        int currentDistance = pq.top().first;
        int u = pq.top().second;

        pq.pop();

        if (currentDistance > dist[u])
            continue;

        for (auto edge : graph[u]) {

            int v = edge.first;
            int weight = edge.second;

            if (dist[u] != INT_MAX &&
                dist[u] + weight < dist[v]) {

                dist[v] = dist[u] + weight;

                parent[v] = u;

                pq.push({
                    dist[v],
                    v
                });
            }
        }
    }

    cout << "Shortest distances from source "
         << source << ":\n";

    for (int i = 0; i < V; i++) {

        cout << "Vertex " << i
             << " : ";

        if (dist[i] == INT_MAX)
            cout << "INF";

        else
            cout << dist[i];

        cout << endl;
    }
}

int main() {

    int V = 6;

    vector<vector<PII>> graph(V);

    auto addEdge = [&](int u, int v, int w) {

        graph[u].push_back({v, w});
        graph[v].push_back({u, w});

    };

    addEdge(0, 1, 4);
    addEdge(0, 2, 2);
    addEdge(1, 2, 1);
    addEdge(1, 3, 5);
    addEdge(2, 4, 8);
    addEdge(3, 4, 2);
    addEdge(3, 5, 3);
    addEdge(4, 5, 1);

    dijkstra(V, graph, 0);

    return 0;
}
```

7. Complexity Analysis

Using Priority Queue

O((V + E) log V)

Using Adjacency Matrix

O(V²)

Space Complexity

O(V + E)

Edge Restriction

Edge weights must be non-negative.
```

```
9. Dijkstra vs Other Shortest Path Algorithms

Algorithm Negative Edges Typical Complexity Use
Dijkstra No O((V+E) log V) Non-negative weighted graph
Bellman-Ford Yes O(VE) Negative edges
Floyd-Warshall Yes* O(V³) All-pairs shortest paths
BFS Not applicable O(V+E) Unweighted graphs

*Floyd-Warshall can handle negative edge weights provided there is no negative cycle.
```
