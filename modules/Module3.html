1. Binary Search Tree (BST) ADT

Definition: A Binary Search Tree is a binary tree in which every node in the left subtree contains values smaller than the node and every node in the right subtree contains values greater than the node.
Left subtree

Values < root

Root

Current node

Right subtree

Values > root

Average Search

O(log n)

Interactive BST

Inorder: -

BST Operations

Operation Average Worst Case
Search O(log n) O(n)
Insert O(log n) O(n)
Delete O(log n) O(n)

BST Pseudocode – Insertion

BST_INSERT(root, key) 1. If root = NULL create a new node return new node 2. If key < root.key root.left = BST_INSERT(root.left, key) 3. Else if key > root.key root.right = BST_INSERT(root.right, key) 4. Return root

BST Pseudocode – Search

BST_SEARCH(root, key) 1. If root = NULL return NOT FOUND 2. If root.key = key return FOUND 3. If key < root.key search left subtree 4. Else search right subtree

BST Pseudocode – Deletion

BST_DELETE(root, key) 1. Search for key. 2. If node is a leaf remove node. 3. If node has one child replace node with its child. 4. If node has two children find inorder successor. copy successor value. delete successor. 5. Return root.

3. Tree Traversals

Tree traversal means visiting every node of a tree exactly once. The four important traversals are:

Inorder Left → Root → Right
Preorder Root → Left → Right
Postorder Left → Right → Root
Level Order Visit nodes level by level.
```
50 / \ 30 70 / \ / \ 20 40 60 80

Interactive Traversal

Select a traversal.

Traversal Pseudocode

INORDER(root) 1. If root = NULL return 2. INORDER(root.left) 3. Visit root 4. INORDER(root.right) PREORDER(root) 1. If root = NULL return 2. Visit root 3. PREORDER(root.left) 4. PREORDER(root.right) POSTORDER(root) 1. If root = NULL return 2. POSTORDER(root.left) 3. POSTORDER(root.right) 4. Visit root LEVEL_ORDER(root) 1. Create an empty queue. 2. Insert root into queue. 3. While queue is not empty: ``` remove front node visit node if left child exists enqueue left child if right child exists enqueue right child
```

C++ Traversal Implementation

void inorder(Node* root) {
    if (root == nullptr)
        return;

    inorder(root->left);
    cout << root->key << " ";
    inorder(root->right);
}

void preorder(Node* root) {
    if (root == nullptr)
        return;

    cout << root->key << " ";
    preorder(root->left);
    preorder(root->right);
}

void postorder(Node* root) {
    if (root == nullptr)
        return;

    postorder(root->left);
    postorder(root->right);
    cout << root->key << " ";
}

void levelOrder(Node* root) {
    if (root == nullptr)
        return;

    queue<Node*> q;
    q.push(root);

    while (!q.empty()) {
        Node* current = q.front();
        q.pop();

        cout << current->key << " ";

        if (current->left)
            q.push(current->left);

        if (current->right)
            q.push(current->right);
    }
}
Important exam point: For a Binary Search Tree, inorder traversal produces keys in sorted order.

2. AVL Tree ADT

Definition: An AVL tree is a self-balancing Binary Search Tree. For every node, the difference between the height of its left and right subtrees is at most 1.
Balance Factor

BF = Height(left) − Height(right)

Valid Values

-1, 0, +1

LL Case

Right Rotation

RR Case

Left Rotation

LR Case

Left + Right Rotation

RL Case

Right + Left Rotation

Interactive AVL Tree

AVL Inorder: -

AVL Rotations

Case Condition Rotation
LL BF > 1 and key < left key Right Rotation
RR BF < -1 and key > right key Left Rotation
LR BF > 1 and key > left key Left then Right
RL BF < -1 and key < right key Right then Left

C++ Implementation – AVL Tree

#include <iostream> #include <algorithm> using namespace std; struct Node { int key; int height; Node *left, *right; ``` Node(int value) { key = value; height = 1; left = right = nullptr; } ``` }; class AVL { private: ``` int height(Node* n) { return n ? n->height : 0; } int balanceFactor(Node* n) { return n ? height(n->left) - height(n->right) : 0; } Node* rightRotate(Node* y) { Node* x = y->left; Node* T2 = x->right; x->right = y; y->left = T2; y->height = 1 + max(height(y->left), height(y->right)); x->height = 1 + max(height(x->left), height(x->right)); return x; } Node* leftRotate(Node* x) { Node* y = x->right; Node* T2 = y->left; y->left = x; x->right = T2; x->height = 1 + max(height(x->left), height(x->right)); y->height = 1 + max(height(y->left), height(y->right)); return y; } Node* insert(Node* node, int key) { if (!node) return new Node(key); if (key < node->key) node->left = insert(node->left, key); else if (key > node->key) node->right = insert(node->right, key); else return node; node->height = 1 + max(height(node->left), height(node->right)); int balance = balanceFactor(node); // LL if (balance > 1 && key < node->left->key) return rightRotate(node); // RR if (balance < -1 && key > node->right->key) return leftRotate(node); // LR if (balance > 1 && key > node->left->key) { node->left = leftRotate(node->left); return rightRotate(node); } // RL if (balance < -1 && key < node->right->key) { node->right = rightRotate(node->right); return leftRotate(node); } return node; } void inorder(Node* root) { if (!root) return; inorder(root->left); cout << root->key << " "; inorder(root->right); } ``` public: Node* root = nullptr; ``` void insert(int key) { root = insert(root, key); } void display() { inorder(root); } ``` }; int main() { ``` AVL tree; tree.insert(30); tree.insert(20); tree.insert(10); tree.display(); return 0; ``` }

3. Splay Tree ADT

Note: “Slay Tree” is generally called a Splay Tree. A Splay Tree is a self-adjusting Binary Search Tree. Whenever a node is accessed, it is moved toward the root using rotations.
Zig

Single rotation

Zig-Zig

Two rotations in same direction

Zig-Zag

Two rotations in opposite directions

Amortized Complexity

O(log n)

C++ Implementation – Splay Tree

#include <iostream> using namespace std; struct Node { int key; Node *left, *right; ``` Node(int value) { key = value; left = right = nullptr; } ``` }; class SplayTree { ``` Node* rightRotate(Node* x) { Node* y = x->left; x->left = y->right; y->right = x; return y; } Node* leftRotate(Node* x) { Node* y = x->right; x->right = y->left; y->left = x; return y; } Node* splay(Node* root, int key) { if (!root || root->key == key) return root; // Key lies in left subtree if (key < root->key) { if (!root->left) return root; // Zig-Zig if (key < root->left->key) { root->left->left = splay(root->left->left, key); root = rightRotate(root); } // Zig-Zag else if (key > root->left->key) { root->left->right = splay(root->left->right, key); if (root->left->right) root->left = leftRotate(root->left); } return root->left ? rightRotate(root) : root; } // Key lies in right subtree else { if (!root->right) return root; // Zig-Zig if (key > root->right->key) { root->right->right = splay(root->right->right, key); root = leftRotate(root); } // Zig-Zag else if (key < root->right->key) { root->right->left = splay(root->right->left, key); if (root->right->left) root->right = rightRotate(root->right); } return root->right ? leftRotate(root) : root; } } ``` public: ``` Node* root = nullptr; void search(int key) { root = splay(root, key); } ``` }; int main() { ``` SplayTree tree; // Insert and search operations // can be implemented using splay() return 0; ``` }

4. B-Tree ADT

Definition: A B-Tree is a balanced multi-way search tree. Unlike a binary tree, a B-Tree node can contain multiple keys and multiple children. B-Trees are widely used in databases and file systems.
Multiple Keys

Each node can store several keys.

Balanced

All leaves occur at the same level.

Database Use

Efficient disk-based searching.

Search

O(log n)

Example B-Tree

[ 30 | 60 ]
[ 10 | 20 ]
[ 40 | 50 ]
[ 70 | 80 | 90 ]

B-Tree Properties

Property Description
Keys Multiple keys per node
Children Multiple children per node
Height Small compared with binary trees
Leaves All leaves at same level
Application Databases, file systems

5. Binary Heap ADT

Definition: A Binary Heap is a complete binary tree that satisfies the heap property. In a Max Heap, the parent is greater than or equal to its children. In a Min Heap, the parent is smaller than or equal to its children.
Max Heap

Parent ≥ Children

Min Heap

Parent ≤ Children

Insert

O(log n)

Delete Root

O(log n)

Peek

O(1)

Interactive Max Heap

Heap Array: [ ]

Array Representation

For a node at index i:

  • Parent = floor((i - 1) / 2)
  • Left child = 2i + 1
  • Right child = 2i + 2

C++ Implementation – Max Heap

#include <iostream> #include <vector> using namespace std; class MaxHeap { ``` vector<int> heap; void heapifyUp(int index) { while (index > 0) { int parent = (index - 1) / 2; if (heap[parent] >= heap[index]) break; swap(heap[parent], heap[index]); index = parent; } } void heapifyDown(int index) { int n = heap.size(); while (true) { int largest = index; int left = 2 * index + 1; int right = 2 * index + 2; if (left < n && heap[left] > heap[largest]) largest = left; if (right < n && heap[right] > heap[largest]) largest = right; if (largest == index) break; swap(heap[index], heap[largest]); index = largest; } } ``` public: ``` void insert(int value) { heap.push_back(value); heapifyUp(heap.size() - 1); } void deleteMax() { if (heap.empty()) return; heap[0] = heap.back(); heap.pop_back(); if (!heap.empty()) heapifyDown(0); } int getMax() { if (heap.empty()) return -1; return heap[0]; } void display() { for (int x : heap) cout << x << " "; cout << endl; } ``` }; int main() { ``` MaxHeap heap; heap.insert(50); heap.insert(30); heap.insert(70); heap.insert(90); heap.insert(20); heap.display(); cout << "Maximum = " << heap.getMax(); return 0; ``` }

6. Comparison of Tree ADTs

Data Structure Search Insert Delete Main Feature
BST O(log n)* O(log n)* O(log n)* Simple ordered binary tree
AVL O(log n) O(log n) O(log n) Strictly balanced BST
Splay O(log n) amortized O(log n) amortized O(log n) amortized Recently accessed nodes move upward
B-Tree O(log n) O(log n) O(log n) Multi-way balanced tree
Binary Heap O(n) O(log n) O(log n) Priority queue

* BST complexities assume a reasonably balanced tree. A highly skewed BST can require O(n) time.

Where Are They Used?

BST

Searching, ordered data, symbol tables.

AVL Tree

Applications requiring consistently fast searching.

Splay Tree

Applications where recently accessed data is likely to be accessed again.

B-Tree

Databases, file systems, storage systems.

Binary Heap

Priority queues, scheduling, Dijkstra's algorithm, heap sort.
