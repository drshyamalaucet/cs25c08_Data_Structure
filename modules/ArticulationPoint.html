🔴 Articulation Point Algorithm

DFS / Tarjan's Algorithm — Interactive Visualization

1. What is an Articulation Point?

An articulation point, also called a cut vertex, is a vertex in a connected graph such that removing that vertex and all of its incident edges increases the number of connected components of the graph.

For a DFS tree: low[v] >= disc[u] ⇒ u is an articulation point

For a non-root vertex u, if it has a child v such that:

low[v] >= disc[u]

then u is an articulation point.

For a DFS root, it is an articulation point if it has more than one DFS child.

3. Important Concepts

Discovery Time

disc[u] stores the time at which vertex u is first visited during DFS.

Low Value

low[u] stores the smallest discovery time reachable from u using DFS-tree edges and at most one back edge.

DFS Tree

DFS produces a tree containing the edges used to discover new vertices.

Back Edge

A back edge connects a vertex to an already visited ancestor in the DFS tree.

4. Algorithm Steps

  1. Perform DFS starting from an unvisited vertex.
  2. Assign a discovery time to every visited vertex.
  3. Initially set: low[u] = disc[u].
  4. For every adjacent vertex v: if v is unvisited, recursively perform DFS.
  5. After processing v: update low[u] = min(low[u], low[v]).
  6. If u is not the DFS root and low[v] >= disc[u], then u is an articulation point.
  7. If u is the DFS root and it has more than one DFS child, then u is an articulation point.

5. Pseudocode

DFS(u):

    visited[u] = true

    disc[u] = low[u] = timer++

    children = 0

    for each v adjacent to u:

        if v is not visited:

            parent[v] = u

            children++

            DFS(v)

            low[u] =
                min(low[u], low[v])

            if parent[u] == -1
               and children > 1:

                u is articulation point

            if parent[u] != -1
               and low[v] >= disc[u]:

                u is articulation point

        else if v != parent[u]:

            low[u] =
                min(low[u], disc[v])

6. C++ Implementation

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

class Graph {

    int V;

    vector<vector<int>> adj;

    vector<int> disc;
    vector<int> low;
    vector<int> parent;

    vector<bool> visited;
    vector<bool> articulation;

    int timer;

public:

    Graph(int vertices) {

        V = vertices;

        adj.resize(V);

        disc.resize(V, -1);
        low.resize(V, -1);
        parent.resize(V, -1);

        visited.resize(V, false);
        articulation.resize(V, false);

        timer = 0;
    }

    void addEdge(int u, int v) {

        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    void DFS(int u) {

        visited[u] = true;

        disc[u] = low[u] = timer++;

        int children = 0;

        for (int v : adj[u]) {

            // Tree edge
            if (!visited[v]) {

                parent[v] = u;

                children++;

                DFS(v);

                low[u] =
                    min(low[u], low[v]);

                // Root condition
                if (parent[u] == -1 &&
                    children > 1) {

                    articulation[u] = true;
                }

                // Non-root condition
                if (parent[u] != -1 &&
                    low[v] >= disc[u]) {

                    articulation[u] = true;
                }
            }

            // Back edge
            else if (v != parent[u]) {

                low[u] =
                    min(low[u], disc[v]);
            }
        }
    }

    void findArticulationPoints() {

        for (int i = 0; i < V; i++) {

            if (!visited[i]) {

                DFS(i);
            }
        }

        cout <<
            "Articulation Points:\n";

        for (int i = 0; i < V; i++) {

            if (articulation[i]) {

                cout << i << " ";
            }
        }

        cout << endl;
    }
};

int main() {

    Graph g(7);

    g.addEdge(0, 1);
    g.addEdge(0, 2);

    g.addEdge(1, 2);
    g.addEdge(1, 3);

    g.addEdge(3, 4);
    g.addEdge(3, 5);

    g.addEdge(4, 5);

    g.addEdge(5, 6);

    g.findArticulationPoints();

    return 0;
}

7. Example

Consider the graph used in the program:

0 — 1 — 3 — 4 \ / \ / 2 5 — 6

The important articulation points are:

  • 1 — removing it disconnects vertex 3 and its subtree.
  • 3 — removing it separates the 4/5/6 portion.
  • 5 — removing it disconnects vertex 6.

8. Complexity Analysis

Time Complexity

O(V + E)

Every vertex and edge is processed a constant number of times.

Space Complexity

O(V + E)

The adjacency list and DFS arrays require linear space.

Algorithm Type

Depth First Search (DFS)

Technique

DFS timestamps + low-link values.

Concept Meaning

Back Edge Edge to an ancestor in DFS
Root Condition More than one DFS child
Non-root Condition low[v] >= disc[u]
